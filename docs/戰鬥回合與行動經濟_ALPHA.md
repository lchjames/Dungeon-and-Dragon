# 戰鬥回合與行動經濟 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：先攻、每回合行動、移動、被動反應／防守、預備反擊、回合開始處理、格仔鄰接。  
> 地圖尺寸、每回合可移動格數、障礙／地形／視線等完整 Map 規則留待後續地圖系統處理。

---

# 1. 先攻只使用 DEX

戰鬥開始時，角色按 DEX 由高至低排列行動順序。

```text
DEX 高者先行動
DEX 低者後行動
```

Alpha 不再另外擲 Initiative 骰。

同 DEX 的正式 Tie Rule 尚未鎖定；Alpha 階段由 GM 手動決定穩定順序即可，不額外增加新判定。

---

# 2. 每回合基本行動經濟

每名角色在自己的正常回合有：

```text
1 次主行動
1 次移動
```

兩者分開保存與消耗。

Alpha 不建立 Bonus Action／Minor Action 等額外全域行動類型。

---

# 3. 主行動

以下預設消耗 1 次主行動：

```text
普通攻擊
使用能力／法術／招式
換武器
飲用藥物
使用一般物品
拾取物品
啟動需要主動操作的裝置
準備彈反／反擊／特殊防守行動
其他需要角色主動完成的主要操作
```

除非某個 Ability／Item／Profile 明確寫有例外，否則以上行為不視為免費動作。

---

# 4. 移動

每回合有 1 次移動。

目前只鎖定：

```text
移動與主行動分開
```

因此角色可以：

```text
先移動，再主行動
或
先主行動，再移動
```

若中途效果改變角色狀態，剩餘移動是否仍可完成依當下狀態處理。

每次移動實際可走幾格，留待 Map 系統正式定義。

---

# 5. 普通反應／防守是被動的

閃避、抵抗、一般防守等反應：

```text
不佔主行動
不佔移動
只有角色實際受到某個攻擊／效果波及時才進行
```

例如：

```text
敵人攻擊角色
→ 角色才進行閃避／防守判定

敵人施加魅惑
→ 角色才進行對應抵抗
```

角色不需要在自己的回合先花主行動「準備普通閃避」。

這些被動反應仍沿用最新 D100 對抗與 Great Result 規則。

---

# 6. 主動型彈反／反擊／特殊防守

某些防守不是普通被動反應，而是角色主動準備的戰術行動，例如：

```text
準備彈反
準備反擊
架勢反制
蓄勢格擋
等待特定攻擊後觸發的特殊能力
```

Alpha Working Rule：

```text
角色在自己回合消耗 1 次主行動
→ 進入「已準備」狀態
→ 指定該能力／招式允許的觸發條件
```

當觸發條件在之後真正發生時：

```text
→ 立即進行該預備行動的結算
```

預備行動與普通被動防守不同：

```text
普通閃避／抵抗
→ 免費被動觸發

彈反／反擊等特殊技巧
→ 先花主行動準備
→ 之後才可在符合條件時觸發
```

Alpha 預設一個「已準備」行動在首次合法觸發後即消耗；若到角色下一個回合開始前仍未觸發，則失效。能力 Profile 可明確覆蓋。

---

# 7. 回合開始處理順序

角色每次自己的回合開始時，依以下順序處理：

```text
1. Buff / Debuff / Temporary Effect 倒數
2. Burning / Poison 等持續傷害 Tick
3. 瀕死倒數
4. Regeneration / 持續恢復
5. 進入正常行動階段
```

這個順序是有意義的。

例如：

```text
角色已瀕死
且仍處於 Burning

→ 先處理 Burning
→ 若造成任何有效傷害
→ 依瀕死規則立即死亡
→ 不再進入後面的瀕死倒數／Regeneration
```

又例如：

```text
瀕死倒數在第 3 步降至 0
→ 立即死亡
→ 第 4 步 Regeneration 不會再救回該角色
```

---

# 8. Temporary Effects 視為 Buff / Debuff 狀態的一部分

Temporary Effect 不建立另一套獨立倒數系統。

例如：

```text
暈眩
加速
緩速
護盾
臨時命中加成
臨時防禦下降
其他有限回合效果
```

均由第 1 步統一處理剩餘回合。

為避免「持續 1 回合」的 Burning／Poison 在首次目標回合開始時先被刪除而完全沒有 Tick，Alpha 採：

```text
回合開始時仍有效的狀態
→ 先記錄／扣減其剩餘回合
→ 本次應有的 start-of-turn Tick 仍可結算
→ 若剩餘回合已到 0，完成本次對應 Tick 後移除
```

如某個 Profile 明確指定其他觸發時點，則依 Profile。

---

# 9. 九宮格鄰接

戰鬥地圖使用格仔系統。

目前只鎖定最基本距離：

```text
以角色所在格為中心
周圍八格全部屬於鄰接格
```

即：

```text
上、下、左、右
以及四個斜角
全部計距離 1
```

概念：

```text
[1][1][1]
[1][我][1]
[1][1][1]
```

因此斜角鄰接不額外計作 1.5 格或 2 格。

完整內容例如：

```text
每回合可移動格數
地形成本
障礙物
高低差
視線
掩體
大型單位佔格
穿越友軍／敵軍
範圍模板
```

留待 Map 系統定義。

# 10. Alpha 回合範例

角色 A 的回合開始：

```text
1. 狀態倒數
2. 中毒造成持續傷害
3. 如 A 正在瀕死，處理瀕死倒數
4. 處理再生
5. A 取得：1 主行動 + 1 移動
```

A 可以：

```text
移動
→ 攻擊
```

或者：

```text
攻擊
→ 移動
```

或者：

```text
移動
→ 使用主行動準備「彈反」
```

敵人 B 之後攻擊 A：

```text
A 仍可進行普通被動防守
```

如果 B 的攻擊同時符合 A 已準備「彈反」的觸發條件：

```text
→ 另按該彈反 Profile 結算預備行動
```

---

# 11. Alpha 鎖定結論

1. Initiative 只以 DEX 排序，高 DEX 先行動。
2. 同 DEX 正式 Tie Rule 待定；Alpha 由 GM 手動定穩定順序。
3. 每回合只有 `1 主行動 + 1 移動`。
4. 換武器、飲藥、拾物、使用一般物品均消耗主行動。
5. 普通閃避／抵抗／防守屬被動反應，只在受到波及時觸發，不消耗主行動或移動。
6. 彈反／反擊／架勢反制等可設為「主動準備」：先消耗主行動，再等待合法觸發。
7. Alpha 預備行動首次合法觸發後消耗；若到下次自己回合開始前未觸發則失效，除非 Profile 另有規定。
8. 回合開始順序為：狀態倒數 → Burning/Poison Tick → 瀕死倒數 → Regeneration → 正常行動。
9. Temporary Effects 併入 Buff/Debuff 狀態倒數，不另建時間系統。
10. 地圖採格仔；以角色為中心的八個相鄰格，包括斜角，全部計距離 1。
11. 每回合移動格數與完整地圖規則留待 Map 系統。
12. 正式狀態、行動、回合與戰鬥資料保存於 D1。
