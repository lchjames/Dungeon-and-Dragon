# Initiative Tie Rule — Alpha

> 狀態：Canonical Alpha Override  
> 日期：2026-08-21  
> 本文件補充並覆蓋 `戰鬥回合與行動經濟_ALPHA.md` 中「同 DEX Tie Rule 待定／由 GM 手動決定」的舊描述。

## 同 DEX 的正式先攻規則

戰鬥開始建立 Combat Turn Order 時，先按 DEX 由高至低排序。

若兩名或以上參戰角色 DEX 相同：

```text
同 DEX 角色
→ 由系統隨機決定彼此先後
→ 產生該場戰鬥的 Turn Order
```

同 DEX 的隨機結果只在建立該次戰鬥 Turn Order 時產生一次；該場戰鬥期間保持相同順序，不會每個 Round 重新隨機。

GM 仍保留既有 Combat Override 權限，但正常流程不需要 GM 手動處理同 DEX tie。

## Alpha 鎖定結論

1. Combat Initiative 以 DEX 由高至低排序。
2. 所有具正常行動資格的參戰角色都會取得自己的 Turn。
3. 同 DEX 時由系統隨機決定相對先後。
4. 隨機 tie-break 在 Combat Start 建立 Turn Order 時進行一次，該場戰鬥內保持穩定。
5. 本規則覆蓋較早「同 DEX 由 GM 手動決定」的暫定規則。
