# 非傷害效果結算 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：減益、控制、位移、精神／感知干擾等非直接傷害效果的 D100 對抗、效果結算、大成功／大失敗。  
> 本文件與 `D100判定核心_ALPHA.md`、`對抗判定與極端結果_ALPHA.md`、`狀態效果標準結構_ALPHA.md` 一起使用。  
> **Canonical Override：** 本文件已覆蓋 `狀態效果標準結構_ALPHA.md` 中「狀態命中與抵抗是否需要對抗判定仍未鎖定」的舊描述；負面非傷害效果現在正式使用 D100 對抗。

---

# 1. 適用範圍

本規則主要處理已通過能力／招式 Profile 定義的非直接傷害效果，例如：

```text
減益
暈眩
定身
沉默
束縛
魅惑
恐懼
幻覺
致盲
擊退
推離
拉近
數值下降
其他非直接 HP 傷害效果
```

直接傷害仍使用 Damage Profile + 傷害骰 + 固定防禦值。

---

# 2. 先經 D100 對抗

任何要向另一方施加負面效果的行動，先進行 D100 對抗。

```text
施加方 Result > 抵抗方 Result
→ 效果成功突破
→ 進入效果結算

施加方 Result <= 抵抗方 Result
→ 效果被抵抗／避開／抵消
→ 不施加效果
```

平手時受影響一方優先，因此負面效果不成立。

---

## 2.1 Great Result 只影響「自己負責的行動」

對抗判定中，施加方與抵抗方都可能擲出原始 1／100，但兩邊的 Great Result **不能互相改寫對方的行動內容**。

Canonical：

```text
施加方的 Great Result
→ 只影響「施加能力／招式」本身

抵抗方的 Great Result
→ 只影響「防守／抵抗行動」本身
```

因此，抵抗方擲出大失敗時，預設不會令施加方的能力突然改飛去隊友、改變原本目標或反向命中其他人。

抵抗方的大成功／大失敗屬於防守側的極端表現，可由 GM + AI 提供 1–3 個情境合理建議，例如：

```text
抵抗大成功：
→ 完全避開並取得更好位置
→ 看穿能力運作方式
→ 順勢拉開距離

抵抗大失敗：
→ 自己失去平衡
→ 暴露破綻
→ 跌倒／碰撞附近物件
→ 其他只屬於防守者自身行動的合理後果
```

這些建議不得自行改寫施加方能力的目標，除非世界狀態真的因防守者自己的動作先發生改變，而且 GM 明確接受該因果。

---

## 2.2 同一次對抗兩邊都出現大失敗

若施加方與抵抗方在同一次對抗都擲出原始 1：

```text
施加方大失敗
→ 能力本身按本文件規則反作用於施加者自己

抵抗方大失敗
→ 抵抗者自己的防守行動亦可產生一個合理不利後果
```

兩者可以同時存在，但不會互相「把效果再彈回去」。

例：

```text
A 對 B 使用束縛
A 原始骰 = 1
B 抵抗原始骰 = 1
```

預設：

```text
束縛反作用於 A
→ A 被自己的束縛影響

B 的抵抗亦嚴重失誤
→ GM + AI 可建議 B 跌倒、失去位置、撞上附近物件等
```

不會變成：

```text
A 大失敗 → 束縛打 A
B 又大失敗 → 再把束縛送回 B
```

如果兩個大失敗的敘事後果互相牽連，AI 可提供 1–3 個「合併後的事件」建議，由 GM 選擇最合理的一個。

---

# 3. 普通成功：照 Profile 正常施加

如果 D100 是普通成功，並且施加方成功壓過抵抗方：

```text
→ 按 Ability / Effect Profile 的正常數值施加
```

例如：

```text
緩速
正常效果：命中判定 -10
持續：2 回合
```

普通成功：

```text
→ 目標命中判定 -10
→ 持續 2 回合
```

---

# 4. 每個非傷害效果指定一個「主要效果值」

為避免大成功同時把所有參數各自 ×2 而令總威力變成四倍甚至更多，每個 Effect Profile 應指定一個：

```text
主要效果值
```

可選類型例如：

```text
持續回合
數值修正
位移距離
層數
目標數量
其他 Profile 明確定義的核心量值
```

例：

```text
暈眩
主要效果值：持續回合
正常：1 回合
```

```text
緩速
主要效果值：數值修正
正常：-10
持續：2 回合
```

```text
擊退
主要效果值：位移距離
正常：3 米
```

```text
魅惑
主要效果值：持續回合
正常：2 回合
```

---

# 5. 大成功：主要效果值 ×2

Alpha Canonical：

```text
施加方原始 D100 = 100
且該負面效果成功突破對抗
→ 大成功
→ 主要效果值 ×2
```

例：

```text
暈眩 1 回合
→ 大成功：2 回合
```

```text
命中 -10，持續 2 回合
主要效果值 = 數值修正
→ 大成功：命中 -20，仍持續 2 回合
```

```text
擊退 3 米
→ 大成功：擊退 6 米
```

```text
魅惑 2 回合
→ 大成功：4 回合
```

重要：

```text
大成功 = 整體效果約雙倍
≠ 每一個欄位都各自 ×2
```

除非能力 Profile 明確定義特殊 Great Success 規則，否則只放大一個主要效果值。

---

# 6. 大失敗：負面效果施加到自己

這條規則只屬於**施加方／能力來源方**的原始 D100 大失敗。

Alpha Canonical：

```text
施加方原始 D100 = 1
→ 大失敗
→ 原本打算施加到目標的負面效果
→ 改為施加到使用者／施術者自己
```

效果使用**正常強度**，不額外 ×2。

例：

```text
對敵人施放：暈眩 1 回合
骰出 1
→ 自己暈眩 1 回合
```

```text
對敵人施放：命中 -10，2 回合
骰出 1
→ 自己命中 -10，2 回合
```

```text
對敵人施放：擊退 3 米
骰出 1
→ 效果反作用於自己
→ 自己按合理方向被移動 3 米
```

抵抗方擲出 1 不使用本條 `SELF_TARGET` 規則，因為抵抗方並不是該負面效果的來源。

---

# 7. 範圍效果的大失敗

如果原能力是以區域為中心的負面效果：

```text
施加方大失敗
→ 預設把效果中心改到施術者自身位置
```

因此原本的範圍、半徑與正常效果仍存在，並可能影響施術者附近其他單位。

例：

```text
沉默領域
原目標：敵方區域
範圍：半徑 3 米
持續：2 回合

施加方大失敗
→ 沉默領域以施術者自身為中心展開
```

具體受影響名單按實際範圍處理。

---

# 8. 無法合理「作用於自己」時

某些負面效果可能無法直接反作用於使用者，例如：

```text
繳械，但使用者當前沒有可被繳械的物品
把目標拉到自己身邊，而「自己拉自己」沒有機械意義
針對特定目標結構的特殊效果
```

此時不要硬造不合理結果。

流程：

```text
施加方大失敗
→ 優先尋找等價的自我不利結果
→ AI 可提供 1–3 個合理建議
→ GM 接受／修改／拒絕
```

仍然遵守核心方向：

```text
大失敗的負面後果優先落在使用者自己
```

---

# 9. 沒有明確數值可以 ×2 的效果

若某效果本身是二元／敘事性效果，沒有自然可乘二的主要數值，例如某些特殊：

```text
沉默
繳械
特殊感知封鎖
特殊條件限制
```

優先順序：

```text
1. 有持續時間 → 將持續時間 ×2
2. 有範圍／距離等明確主要量值 → 將該主要值 ×2
3. 仍無合理量值 → AI 提供 1–3 個「雙倍效果」建議，由 GM 決定
```

不得因為沒有數值就自行新增免費傷害。

---

# 10. 大成功／大失敗與一般 Result 差距分離

普通 D100 Result 的高低仍可以提供 GM／AI 敘事資訊，但施加方的非傷害效果 Great 規則只看：

```text
施加方原始 100 → 大成功
施加方原始 1   → 大失敗
```

例如：

```text
Result +60
但施加方原始骰不是 100
→ 仍是普通成功
→ 不自動 ×2
```

```text
Result -40
但施加方原始骰不是 1
→ 仍是普通失敗
→ 不自動反作用自己
```

抵抗方的原始 1／100 則由防守／抵抗情境推演處理，不套用 `DOUBLE_PRIMARY_EFFECT` 或 `SELF_TARGET`。

---

# 11. AI 的角色

AI 可在以下情況提供 1–3 個建議：

```text
施加方大成功但效果沒有明確可 ×2 的主要數值
施加方大失敗但效果無法合理作用於自己
抵抗方出現大成功／大失敗，需要解讀防守行動的極端後果
雙方同時出現 Great Result，需要整合成一個合理事件
效果牽涉特殊環境／物件／身體結構
需要把機械結果轉成自然敘事
```

AI 只能建議；GM 為最終裁決者。

---

# 12. Effect Profile 建議欄位

非傷害效果應至少可保存：

```text
Effect Profile
├── effect_type
├── target_mode
├── base_value
├── duration_rounds
├── primary_effect_field
├── stacking_rule
├── resistance_type
├── great_success_rule
├── great_failure_rule
└── metadata
```

Alpha 預設：

```text
great_success_rule = DOUBLE_PRIMARY_EFFECT
great_failure_rule = SELF_TARGET
```

這兩個預設只適用於效果來源／施加方；抵抗方的 Great Result 使用防守側情境推演。

如某能力有專屬規則，可由 Profile 明確覆蓋。

---

# 13. Alpha 鎖定結論

1. 負面非傷害效果先經 D100 對抗；施加方必須嚴格高於抵抗方。
2. Great Result 有結果歸屬：施加方只影響能力本身；抵抗方只影響防守／抵抗本身。
3. 抵抗方大失敗不會預設把施加方能力改飛去隊友或其他目標。
4. 普通成功按 Effect Profile 正常施加。
5. 每個非傷害 Effect Profile 指定一個「主要效果值」。
6. 施加方原始 100 大成功：主要效果值 ×2。
7. 不會把強度與持續時間等所有欄位同時各自 ×2。
8. 施加方原始 1 大失敗：原本負面效果改為作用於使用者自己，正常強度。
9. 抵抗方原始 1／100 不使用 `SELF_TARGET`／`DOUBLE_PRIMARY_EFFECT`，而由 GM + AI 對防守行動本身作 1–3 個情境建議。
10. 雙方同時大失敗時，施加方效果反作用自己；抵抗方可另外承受自己的防守失誤，不會把效果再彈回原目標。
11. 範圍效果施加方大失敗時，預設把範圍中心移到施術者自身。
12. 若效果無法合理自我作用，AI 提供 1–3 個等價自我不利建議，GM 決定。
13. 若大成功沒有可自然 ×2 的數值，優先倍增持續時間／主要範圍；仍無合理量值時由 AI 提供 1–3 個建議。
14. 普通 Result 差距不會自動觸發 Great 規則；Great 只由原始 1／100 觸發。
15. AI 是建議與合理化工具，GM 為最終裁決者。
16. 正式資料保存於 D1。
