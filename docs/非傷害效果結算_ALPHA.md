# 非傷害效果結算 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：正面／負面非直接傷害效果、D100 對抗、大成功／大失敗、防守 Great、雙重大失敗、AI + GM 情境解讀。  
> 本文件與 `D100判定核心_ALPHA.md`、`對抗判定與極端結果_ALPHA.md`、`狀態效果標準結構_ALPHA.md` 一起使用。  
> **Canonical Override：** 本文件覆蓋較早「大失敗固定 SELF_TARGET」、「Great Result 只能各自處理自己行動」以及「100 vs 100 使用特殊 Great 對撞」的舊版本。

---

# 1. 核心原則

Great Result 描述行動的極端表現，不直接保證故事最後對角色有利或不利。

```text
大成功
= 行動被極高程度完成／放大

大失敗
= 行動嚴重偏離原本意圖
```

因此：

```text
大成功 ≠ 一定是好事
大失敗 ≠ 一定是壞事
```

例如治療術大失敗誤中不死敵人，而該敵人的 Profile 規定治療能量會轉成傷害，則大失敗仍可能意外幫到玩家。

---

# 2. 正面與負面效果共用同一 Great 邏輯

包括：

```text
正面：
治療、增益、護盾、加速、再生、淨化、強化、正面位移

負面：
暈眩、定身、束縛、魅惑、恐懼、幻覺、致盲、沉默、擊退、減益、控制
```

一般：

```text
願意接受的正面效果
→ 通常只有來源方判定

負面／強制效果
→ 來源方 vs 抵抗方 D100 對抗
```

如果目標拒絕一個正面效果，GM 可按強制施加處理並要求對抗。

---

# 3. 對抗永遠先比較 Result

所有直接對抗先使用正常 D100 Result：

```text
來源方 Result > 抵抗方 Result
→ 來源方突破

來源方 Result <= 抵抗方 Result
→ 抵抗方成功
```

對負面效果而言，平手採「受影響一方微弱優勢」：

```text
平手
→ 負面效果不成立
```

Great Result 不會跳過這條核心比較規則。

---

# 4. 100 vs 100 仍使用普通對抗與弱勢方優先

如果雙方原始骰都是 100：

```text
來源方 = 100
抵抗方 = 100
```

仍然先比較各自最終 Result。

```text
來源方 Result > 抵抗方 Result
→ 來源方勝
→ 若效果成功落地，來源方大成功規則生效

來源方 Result < 抵抗方 Result
→ 抵抗方勝
→ 抵抗方大成功防守規則生效

來源方 Result = 抵抗方 Result
→ 負面效果方未能嚴格壓過
→ 抵抗方勝
→ 抵抗方大成功防守規則生效
```

因此：

```text
100 vs 100
≠ 自動抵消 Great
≠ 自動重骰
≠ 自動來源方勝
```

它完全遵守既有弱勢方／受負面影響方平手優先規則。

---

# 5. 對抗差距敘事最多只看 ±20

實際 Result 永遠保留完整數字。

```text
對抗差距
= 來源方 Result - 抵抗方 Result

敘事對抗差距
= clamp(對抗差距, -20, +20)
```

±20 只限制 AI／GM 描述強度，不改變：

```text
誰勝出
是否突破
效果實際數值
```

---

# 6. 來源方大成功：主要效果值 ×2

每個 Effect Profile 指定一個主要效果值，例如：

```text
持續回合
數值修正
位移距離
治療量
護盾量
層數
範圍
目標數量
其他 Profile 明確核心量值
```

若來源方原始 D100 = 100，而且來源方實際勝出／效果成功落地：

```text
大成功
→ 主要效果值 ×2
```

例：

```text
暈眩 1 回合 → 2 回合
擊退 3 米 → 6 米
治療 10 → 20
命中 -10（主要值）→ -20
```

不會把所有欄位同時 ×2，避免強度 ×2、時間 ×2、範圍 ×2 造成實際多倍膨脹。

如果來源方骰到 100 但最終仍被抵抗方壓過／平手擋住：

```text
→ 原目標不吃效果
```

但該次原始骰仍屬大成功，可供技能成長與敘事解讀使用；GM／AI可描述成「非常強的施放被同樣強甚至更強的抵抗擋下」。

---

# 7. 來源方大失敗：效果嚴重偏離，不固定打自己

來源方原始 D100 = 1：

```text
→ 行動嚴重偏離原本意圖
→ 不使用全域 SELF_TARGET
```

AI + GM 根據場景提供 1–3 個合理偏離結果，例如：

```text
誤中自己
誤中隊友
誤中另一名敵人
中心點偏移
效果落到環境／物件
方向反轉
效果浪費
其他符合 Profile 的偏離
```

預設仍使用正常效果強度，不因大失敗自動 ×2。

Great Failure 描述的是「失去控制」，而不是「系統必須懲罰玩家」。

---

# 8. 抵抗方正式加入 Great 系統

抵抗不是「沒有 Great」。但抵抗本身通常沒有一個可簡單 ×2 的 Effect Value，因此防守 Great 使用不同語義。

## 8.1 抵抗方大成功：完美防守／抵抗

抵抗方原始 D100 = 100。

仍然先比較 Result。

若抵抗方勝出或因平手規則勝出：

```text
→ 原負面效果完全不成立
→ 標記為「抵抗大成功／完美防守」
→ AI + GM 可提供 1–3 個防守優勢建議
```

防守優勢建議可按行動類型包括：

```text
閃避：
→ 順勢移到更好位置
→ 進入掩體
→ 拉開／縮短到有利距離

格擋／招架：
→ 把力量導向安全方向
→ 令對方武器／攻擊路線短暫偏開
→ 保持極佳架勢

精神／意志抵抗：
→ 看穿能力運作方式
→ 察覺施術特徵或弱點
→ 完全不被精神干擾

束縛／控制抵抗：
→ 順勢脫離控制區
→ 令束縛落到無害環境物件
→ 保持行動節奏
```

這些是 **1–3 個 GM/AI 建議**，不是全域免費 Buff、免費反擊或固定 +X。

如建議要轉成正式機械收益（例如下一次判定 +5、免費移動、反擊），仍需 GM 明確接受並由相應規則支援。

## 8.2 抵抗方大成功但仍輸

極端情況下，抵抗方即使原始骰 100，也可能因技能值／修正差距被來源方 Result 壓過。

此時：

```text
→ 來源方仍然突破
→ 不因「抵抗骰 100」自動改寫勝負
```

但 AI／GM 可描述成：

```text
抵抗已做到自身極限，仍被更強大的力量壓過
```

不額外送防守收益。

# 9. 抵抗方大失敗：防守嚴重失誤

抵抗方原始 D100 = 1：

```text
→ 抵抗／閃避／防守行動嚴重失誤
```

仍然先看 Result 決定原效果是否突破。

AI + GM 可提供 1–3 個防守失誤建議，例如：

```text
失去平衡
移錯方向
暴露位置
撞到附近障礙物
武器／盾牌姿勢失衡
把自己帶到更差地形
錯判能力方向
其他合理失誤
```

重要：

```text
抵抗大失敗
≠ 自動令來源效果 ×2
```

否則來源大成功 + 抵抗大失敗會疊成 ×4，破壞目前簡單 Alpha 設計。

來源效果是否 ×2，只由來源方本身的大成功規則決定。

即使抵抗方骰到 1，但靠極高技能／修正仍然在 Result 上勝出，原負面效果仍可被擋下；只是防守行動本身仍可能出現一個大失敗式的附帶失誤，由 GM／AI 合理化。

---

# 10. 雙方同時大失敗：兩個錯誤可以互相抵消

直接對抗中：

```text
來源方原始骰 = 1
抵抗方原始骰 = 1
```

Alpha 保留特殊有趣規則：

```text
雙重大失敗
→ 兩個錯誤互相抵消
→ 原本意圖的效果意外落在原本目標
→ 使用正常強度
```

例如：

```text
A 束縛射歪
B 又剛好向錯誤方向閃
→ B 自己走入偏掉的束縛路徑
→ 束縛成功
```

```text
大失敗 + 大失敗
= 意外成功
≠ 大成功
```

所以不會 ×2。

GM + AI 可另外提供 1–3 個混亂但合理的附帶描述；任何正式額外傷害／Debuff 仍需相應規則支持。

這是少數會覆蓋普通 Result 勝負的特殊 Great Interaction。

# 11. Great 對撞簡表

| 來源方原始骰 | 抵抗方原始骰 | 處理 |
|---|---|---|
| 100 | 普通 | 先比 Result；來源勝出並落地時主要效果 ×2 |
| 普通 | 100 | 先比 Result；抵抗勝出／平手時觸發完美防守建議 |
| 100 | 100 | **完全按 Result 比較；平手由抵抗方勝**；勝方套用自己的 Great 規則 |
| 1 | 普通 | 來源效果進入偏離結果；AI/GM 1–3 建議 |
| 普通 | 1 | 先比 Result；抵抗方有防守大失敗附帶結果 |
| 100 | 1 | 先比 Result；來源若成功落地只 ×2 一次；抵抗失誤可另有敘事，但不再乘效果 |
| 1 | 100 | 通常抵抗方更可能擋下；仍按 Result，來源偏離 + 防守極端表現由 AI/GM 整合 |
| 1 | 1 | **雙重大失敗 → 原目標正常吃到效果，正常強度** |

# 12. 正面效果與特殊目標 Profile

正面效果的大失敗可以誤中敵人。

例如：

```text
玩家治療隊友
→ 大失敗
→ 治療誤中敵人
```

如果敵人是普通生物：

```text
→ 敵人獲得治療
```

如果不死 Profile 定義：

```text
治療能量 → 傷害
```

則：

```text
→ 按目標 Profile 轉化成傷害
```

Great Failure 仍然成立，因為原本行動沒有按玩家意圖完成。

同理，毒素、Buff、淨化、元素效果等都可被目標自身的免疫／吸收／轉換規則改寫最後世界結果。

---

# 13. AI 的角色

AI 在 Great Result 中主要負責：

```text
讀取雙方 Result、原始骰與 Great 標記
理解來源能力與抵抗方式
讀取位置、環境與合法目標
理解種族／弱點／免疫／轉換 Profile
提供 1–3 個合理結果候選
解釋直接因果與可能次生效果
```

AI 不得：

```text
跳過 Result 勝負規則
把 100 自動當成無條件勝利
因抵抗大失敗而把來源效果再乘二
偷偷創造免費 Buff／Debuff／反擊
```

GM 為最終裁決者。

---

# 14. Effect Profile 建議欄位

```text
Effect Profile
├── effect_type
├── target_mode
├── base_value
├── duration_rounds
├── primary_effect_field
├── stacking_rule
├── resistance_type
├── great_success_rule
├── great_failure_rule
├── target_validity_rules
└── metadata
```

Alpha 預設：

```text
great_success_rule = DOUBLE_PRIMARY_EFFECT
great_failure_rule = TARGET_DEVIATION
```

抵抗方 Great 不需要複製以上 Effect Profile 規則；由對抗 Resolver 記錄：

```text
DEFENSE_GREAT_SUCCESS
DEFENSE_GREAT_FAILURE
```

再由 GM + AI 按抵抗類型提供 1–3 個建議。

# 15. Alpha 鎖定結論

1. 對抗永遠先比較 D100 Result；Great 不會直接跳過基本勝負規則。
2. 負面效果來源方必須嚴格高於抵抗方；平手由受影響／抵抗方勝。
3. **100 vs 100 仍正常比較 Result；完全相同時抵抗方勝。**
4. 對抗敘事差距最多使用 `-20 ~ +20`，只供描述／AI 推演。
5. 來源方原始 100 且效果成功落地：主要效果值 ×2。
6. 來源方原始 1：效果嚴重偏離原意，由 AI + GM 提供 1–3 個合理偏離結果。
7. 抵抗方正式加入 Great 系統。
8. 抵抗方原始 100 且成功抵抗：屬「完美防守」，AI + GM 提供 1–3 個合理防守優勢建議；不自動給固定數值 Buff／反擊。
9. 抵抗方原始 1：防守／抵抗嚴重失誤，可產生 1–3 個合理附帶後果；不自動令來源效果 ×2。
10. 任何 Great 防守仍受 Result 最終勝負約束；100 不是自動勝利。
11. 來源大成功 + 抵抗大失敗最多只由來源大成功提供一次 ×2，不疊成 ×4。
12. **1 vs 1 保留雙重大失敗互相抵消 → 原目標正常吃到效果，正常強度。**
13. Great Failure 不保證故事對玩家不利；目標 Profile、環境及連鎖反應仍可令意外結果反而有利。
14. AI 提供 1–3 個情境合理建議；GM 為最終裁決者。
15. 正式 Profile、狀態與裁決結果保存於 D1。
