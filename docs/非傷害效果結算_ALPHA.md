# 非傷害效果結算 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：正面／負面非直接傷害效果、D100 對抗、大成功／大失敗、雙重大失敗、AI + GM 情境解讀。  
> 本文件與 `D100判定核心_ALPHA.md`、`對抗判定與極端結果_ALPHA.md`、`狀態效果標準結構_ALPHA.md` 一起使用。  
> **Canonical Override：** 本文件覆蓋較早「大失敗固定 SELF_TARGET」與「Great Result 只能各自處理自己行動、不可互相抵消」的版本。

---

# 1. 核心原則：Great Result 描述行動偏差，不保證故事好壞

Canonical：

```text
大成功
= 行動效果被超額完成／放大

大失敗
= 行動嚴重偏離原本意圖
```

因此：

```text
大成功 ≠ 一定對玩家有利
大失敗 ≠ 一定對玩家有害
```

例：

```text
治療術大失敗
→ 沒有落在原本想治療的隊友
→ 可能誤中敵人
```

如果該敵人是普通生物：

```text
→ 可能真的治療敵人
```

如果該世界／目標 Profile 定義：

```text
不死生物受到治療能量時會受傷
```

則：

```text
同一次「治療術大失敗」
→ 誤中不死敵人
→ 反而造成傷害
```

機械標記仍然是「大失敗」，因為角色沒有按原意完成行動；只是世界規則令意外結果反而有利。

同理：

```text
毒素誤中對毒素有吸收／強化特性的生物
→ 可能反而 Buff 對方
```

Great Result 不覆蓋目標自身的種族、免疫、弱點、轉換或特殊 Profile。

---

# 2. 正面與負面非傷害效果都使用同一套 Great 邏輯

本文件不限於 Debuff。

可包括：

```text
正面：
治療
增益
護盾
加速
再生
淨化
強化
正面位移／傳送

負面：
暈眩
定身
束縛
魅惑
恐懼
幻覺
致盲
沉默
擊退
減益
其他控制／不利效果
```

是否需要對抗由「目標是否抵抗／效果是否屬強制施加」決定。

一般：

```text
願意接受的正面效果
→ 通常只需要來源方判定

負面／強制效果
→ 來源方 vs 抵抗方 D100 對抗
```

如果某角色拒絕一個正面效果，例如敵人拒絕被強制治療，GM 可以把它當成對抗效果處理。

---

# 3. 普通負面對抗仍使用嚴格突破

```text
來源方 Result > 抵抗方 Result
→ 成功突破
→ 效果落在原本目標

來源方 Result <= 抵抗方 Result
→ 抵抗成功
→ 效果不成立
```

平手時，受負面影響的一方有微小優勢：

```text
平手
→ 負面效果不成立
```

這條普通規則不變。

---

# 4. 對抗差距的敘事值最多只看 ±20

實際 Result 不截斷，但供 GM／AI 解讀「壓過幾多」時：

```text
對抗差距
= 來源方 Result - 抵抗方 Result

敘事對抗差距
= clamp(對抗差距, -20, +20)
```

這個 ±20 只影響描述與 AI 推演，不改變：

```text
誰勝出
是否突破
效果實際數值
```

例如：

```text
實際差距 +47
→ 仍保存 +47
→ 敘事只視為 +20 級壓倒性突破
```

```text
實際差距 -39
→ 仍保存 -39
→ 敘事只視為 -20 級壓倒性抵抗
```

# 5. 大成功：主要效果值 ×2

每個 Effect Profile 指定一個主要效果值，例如：

```text
持續回合
數值修正
位移距離
治療量
護盾量
層數
範圍
目標數量
其他 Profile 明確核心量值
```

來源方原始 D100 = 100，且效果實際成功落地時：

```text
大成功
→ 主要效果值 ×2
```

例：

```text
暈眩 1 回合
→ 2 回合
```

```text
命中 -10，持續 2 回合
主要效果值 = 數值修正
→ -20，仍持續 2 回合
```

```text
擊退 3 米
→ 6 米
```

```text
治療 10
→ 20
```

重要：

```text
大成功 = 整體效果約雙倍
≠ 所有欄位全部 ×2
```

不可同時把強度、時間、範圍、目標數全部各自 ×2，除非 Profile 有專屬 Great Success 規則。

---

# 6. 大失敗：預設為「效果嚴重偏離原意」，不再固定 SELF_TARGET

來源方原始 D100 = 1：

```text
→ 效果沒有按原本意圖正確落地
→ 進入「偏離結果」
```

Alpha 不再固定：

```text
大失敗 = 一定打自己
```

而是由 GM + AI 根據：

```text
原本目標
射程／範圍
附近合法目標
施術者位置
隊友／敵人位置
能力類型
環境
目標條件
世界規則
```

提供 **1–3 個合理偏離建議**。

常見可能性：

```text
誤中自己
誤中隊友
誤中敵方其他角色
中心點偏移
作用到錯誤物件／區域
效果方向反轉
其他合理但偏離原意的結果
```

GM 選擇／修改／拒絕。

預設效果使用正常強度，不因大失敗自動 ×2。

---

# 7. 正面效果大失敗可以誤中敵人

這是正式允許的結果。

例如：

```text
A 想治療隊友 B
A 原始骰 = 1
```

AI／GM 可按位置提供：

```text
1. 治療能量誤中最近的敵人 C。
2. 能量回流到 A 自己。
3. 治療落到另一名受傷角色 D。
```

如果選擇 C：

```text
C 是普通生物
→ C 按正常規則受到治療
```

但如果：

```text
C 是不死生物
且 C 的 Profile 定義治療能量會轉化為傷害
```

則按 C 的 Profile 處理。

所以：

```text
大失敗的「失敗」
= 失去原本控制／目標
≠ 系統必須強行找到一個對玩家最壞的結果
```

---

# 8. 抵抗方大成功／大失敗

抵抗方的 Great Result 描述抵抗行動本身，但可以影響整個事件的最終合理化。

## 抵抗方原始 100

```text
→ 抵抗大成功
```

正常仍比較 Result。

若抵抗成功，AI／GM 可提供 1–3 個額外敘事建議，例如：

```text
完全避開並取得更好位置
看穿能力運作方式
借勢拉開距離
讓束縛纏到環境物件而非自身
```

不自動產生免費 Buff／反擊。

## 抵抗方原始 1

```text
→ 抵抗大失敗
```

正常仍比較 Result，但抵抗行動本身嚴重出錯。

若效果成功突破，可由 AI／GM提供 1–3 個額外情境建議，例如：

```text
失去平衡
暴露位置
錯誤移動
撞到附近障礙物
讓自己處於更差姿勢
```

抵抗大失敗本身不固定將能力改飛去其他人；但它可以和來源方的 Great Result 共同形成特殊互動。

---

# 9. 雙方同時大失敗：兩個錯誤互相抵消

這是 Alpha 的特殊有趣規則。

在一次直接對抗中：

```text
來源方原始骰 = 1
抵抗方原始骰 = 1
```

Canonical Override：

```text
雙重大失敗
→ 兩個錯誤互相抵消
→ 原本意圖的效果落在原本意圖的目標
→ 使用正常強度
```

也就是：

```text
大失敗 + 大失敗
= 意外成功
```

例：

```text
A 對 B 使用束縛
A 大失敗：束縛方向本來嚴重偏掉
B 大失敗：B 又剛好向錯誤方向閃避

→ B 反而自己走進偏掉的束縛路徑
→ 束縛成功命中 B
→ 正常強度
```

這個特殊結果**直接覆蓋普通 Result 比較的成敗**，避免兩邊 Great Failure 再互相彈來彈去。

但：

```text
雙重大失敗 ≠ 大成功
```

所以不會 ×2。

GM + AI 可以另外提供 1–3 個輕度／情境性附帶描述，例如：

```text
施術者姿勢狼狽
目標因錯誤閃避跌倒後被束縛
能力落地方式非常混亂
附近物件被波及但沒有額外機械效果
```

任何正式額外 Debuff／傷害仍需 GM 批准及相應規則支持。

---

# 10. 其他 Great 對撞的簡單處理

Alpha 先保持簡單：

| 來源方 | 抵抗方 | 預設處理 |
|---|---|---|
| 100 | 1 | 若效果落地，主要效果值 ×2；抵抗方可有大失敗敘事 |
| 100 | 100 | 仍比較 Result；來源方嚴格勝出才落地，落地則 ×2 |
| 1 | 100 | 原目標通常成功避開；來源效果進入偏離結果，由 AI／GM 提 1–3 建議 |
| 1 | 1 | **雙重大失敗 → 原目標正常吃到效果** |

非極端組合一律回到普通 Result 比較。

---

# 11. Great Failure 不保證負面結果

這是正式設計原則。

例如：

```text
玩家用 Buff 想強化隊友
→ 大失敗
→ Buff 誤中敵人
→ 通常對玩家不利
```

但：

```text
玩家用治療想救隊友
→ 大失敗
→ 治療誤中不死敵人
→ 不死 Profile 將治療轉成傷害
→ 結果反而幫到玩家
```

這沒有破壞 Great Failure。

因為大失敗描述的是：

```text
玩家沒有成功控制自己原本想做的事情
```

而不是：

```text
宇宙必須確保玩家受到懲罰
```

# 12. 無自然 ×2 或無合理偏離目標時

## 大成功沒有自然主要值

優先：

```text
1. 持續時間 ×2
2. 合理範圍／距離 ×2
3. 仍無法量化 → AI 提供 1–3 個約雙倍效果建議
```

## 大失敗沒有合理錯誤目標

例如：

```text
場上只有施術者與唯一原目標
效果只可作用特定類型目標
```

則：

```text
AI + GM 提供 1–3 個合理「控制失誤／偏離」結果
```

可包括：

```text
作用自己（若合法）
中心偏移
效果浪費
作用到環境
方向錯誤
其他 Profile 合法偏差
```

不需要硬套 SELF_TARGET。

---

# 13. AI 的角色

AI 在 Great Result 中主要負責：

```text
讀取場景位置與合法目標
理解 Ability / Effect Profile
理解目標種族／弱點／免疫／轉換規則
提供 1–3 個合理結果候選
解釋因果
```

AI 不負責：

```text
偷偷改能力數值
因為結果看起來好笑就忽略 Profile
自動創造免費傷害／Debuff
強迫選最壞結果
```

GM 保留最終裁決權。

---

# 14. Effect Profile 建議欄位

```text
Effect Profile
├── effect_type
├── target_mode
├── base_value
├── duration_rounds
├── primary_effect_field
├── stacking_rule
├── resistance_type
├── great_success_rule
├── great_failure_rule
├── target_validity_rules
└── metadata
```

Alpha 預設：

```text
great_success_rule = DOUBLE_PRIMARY_EFFECT
great_failure_rule = TARGET_DEVIATION
```

不再以 `SELF_TARGET` 作全域預設。

---

# 15. Alpha 鎖定結論

1. Great Result 描述行動完成／偏離程度，不直接代表故事對玩家有利或不利。
2. 正面與負面非傷害效果使用同一套 Great 邏輯。
3. 負面效果普通對抗仍要求來源方 Result 嚴格高於抵抗方；平手時負面效果不成立。
4. 對抗敘事差距最多使用 `-20 ~ +20`，只供描述／AI 推演，不改機械結果。
5. 來源方原始 100：效果成功落地時，主要效果值 ×2。
6. 大成功不會把所有欄位同時 ×2。
7. 來源方原始 1：改為 `TARGET_DEVIATION`，由 AI + GM 提供 1–3 個合理偏離結果，不再固定作用自己。
8. 正面效果大失敗可以誤中敵人；結果按該目標自身 Profile 處理。
9. Great Failure 不保證對玩家不利；意外結果可能因世界規則反而有利。
10. 抵抗方原始 1／100仍可產生自身極端抵抗敘事，但不自動得到免費機械效果。
11. **來源方 1 + 抵抗方 1 = 雙重大失敗互相抵消；原本效果命中原本目標，正常強度。**
12. 雙重大失敗不是大成功，不會 ×2。
13. 其他 Great 對撞依簡單表處理；非極端組合回到普通 Result 比較。
14. AI 提供 1–3 個情境合理建議；GM 為最終裁決者。
15. 正式 Profile、狀態與裁決結果保存於 D1。
