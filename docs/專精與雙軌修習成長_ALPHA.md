# 專精與雙軌修習成長 — Alpha

> 狀態：Canonical Alpha Override  
> 範圍：九屬性修習、物理專精、武器／徒手使用成長、魔法使用成長、能力使用後的進度分配。  
> 本文件覆蓋較早規格中任何把「專精」只視為固定手動授予 Buff、或把不同武器拆成獨立基礎技能值的衝突描述。

---

## 1. 核心方向

角色的實際使用行為可以產生修習進度。

但物理與魔法的成長結構不同：

```text
物理行動
→ 物理屬性修習
+ 對應專精修習

元素魔法行動
→ 對應元素修習
```

因此物理是一套「雙軌修習」，而一般元素魔法是一套「單軌修習」。

---

## 2. 九屬性修習仍然存在

角色保留九種屬性：

```text
物理
光
暗
火
水
風
土
雷
木
```

每種屬性都有自己的：

```text
階級
修習進度／經驗
```

具體每階所需經驗值、每次使用獲得多少進度、高階成長曲線等數值，留待 Alpha Build 調整，不在本文件鎖死。

---

## 3. 專精是第二條永久成長軌

物理角色除了「物理」屬性修習外，可以對實際使用的戰鬥方式形成專精。

例如：

```text
劍類專精
刀類專精
槍／矛類專精
錘類專精
棍／杖類專精
徒手專精
遠程專精
投擲專精
```

Alpha 不必一開始鎖死完整分類；可按實際裝備／能力標籤增加。

專精本身包含：

```text
專精進度／經驗
專精成長階段／等級（具體尺度 Alpha Build 再定）
由專精提供的永久修正／常駐增益
```

專精不是另一套 0–99 武器技能值，也不預設決定某把武器能否使用。

---

## 4. 物理使用同時增加兩種進度

當角色以某種物理來源完成有效使用時，系統同時增加：

```text
A. 物理屬性修習
B. 對應專精修習
```

例如角色用劍進行有效攻擊／物理能力：

```text
物理修習 +X
劍類專精修習 +Y
```

用錘：

```text
物理修習 +X
錘類專精修習 +Y
```

徒手：

```text
物理修習 +X
徒手專精修習 +Y
```

因此兩個角色即使物理階級相同，也可以因長期使用不同戰鬥方式而形成不同永久專精。

---

## 5. 元素魔法一般只增加對應元素修習

一般純魔法使用不建立武器式第二專精軌。

例如：

```text
火球術
→ 火屬性修習 +X
```

```text
雷擊術
→ 雷屬性修習 +X
```

```text
治癒之光
→ 光屬性修習 +X
```

預設不會因使用「火球術」另外增加「火球專精」或「法杖專精」。

若未來確立獨立魔法學派／流派專精，可另行加入，但不屬於目前 Alpha 核心。

---

## 6. 附魔魔法的成長分開處理

附魔魔法仍然屬於魔法 Buff。

例如角色施放：

```text
火焰附魔
```

施放本身屬於火元素魔法行為：

```text
火屬性修習 +X
```

之後角色用已被附魔的劍攻擊：

```text
物理修習 +X
劍類專精修習 +Y
```

不因為該劍當前帶有火焰附魔，就在每次劍擊額外增加火屬性修習。

原因：

```text
施放附魔
= 火元素操控行為

附魔後揮劍
= 物理／劍類操控行為
```

這可以避免同一個 Buff 在多次攻擊中重複刷取元素修習。

---

## 7. 物理能力仍按實際來源決定專精

具名物理能力本身不需要建立另一條專精。

例如：

```text
月牙斬
屬性：物理
使用來源：劍
```

成功／有效使用時：

```text
物理修習
+
劍類專精修習
```

例如：

```text
震地重擊
屬性：物理
使用來源：錘
```

則增加：

```text
物理修習
+
錘類專精修習
```

所以「招式名稱」與「專精成長項目」分離；專精跟實際使用方式，而不是每個招式各自建立經驗條。

---

## 8. 混合型能力可有多個成長標籤

如果未來出現真正同時要求兩種主動操控的混合能力，例如：

```text
物理劍技 + 主動火元素操控
```

系統可允許能力定義帶有多個「修習成長標籤」。

概念例：

```text
主要屬性成長：物理
次要屬性成長：火
專精成長：劍類
```

但這必須由能力定義／GM 明確設定。

普通「火焰附魔後揮劍」不自動視為混合型能力，仍按第 6 節分開計算。

Alpha Build 再決定多標籤能力的實際進度分配比例。

---

## 9. 專精提供的是永久／常駐成長效果

專精提升後，得到的收益屬於角色長期成長的一部分。

例如未來可由 Alpha Build 定義某些專精階段提供：

```text
符合武器類別時的判定加值
符合武器類別時的傷害修正
穩定度／控制修正
特定物理效果加成
其他永久修正
```

這些效果本質上屬於常駐增益／永久修正。

但專精成長本身不代表：

```text
自動學會新的具名招式
自動取得高階能力
自動解鎖技能樹節點
```

具名能力仍需要透過導師、學校、卷軸、秘籍、商店、物品、劇情或 GM 授予等方式取得。

---

## 10. 專精與能力使用資格保持分離

例如角色：

```text
物理：4階
劍類專精：很高
```

不代表角色自動擁有所有四階劍技。

同樣：

```text
物理：4階
劍類專精：很低
```

也不代表角色完全不能拿劍或使用已取得的劍技；是否可使用仍看該能力自己的正式條件。

如某個特殊能力要求：

```text
劍類專精達到指定門檻
```

才將專精作為明確前置條件。

---

## 11. 「每次使用」的 Alpha 技術定義

Canonical 方向是：

> 每次有效使用可以增加相應修習進度。

但「有效使用」的具體判定與每次給多少經驗，留到 Alpha Build。

Alpha Build 應避免無限重複無風險動作造成失控刷取，例如：

```text
對空揮劍數千次
反覆對沒有威脅的固定目標施放同一能力
沒有實際訓練／戰鬥價值的重複操作
```

可測試的處理方法包括：

```text
有效戰鬥／訓練事件才計算
同一低風險行為遞減收益
每回合／每場戰鬥上限
按難度／成功程度調整
由 GM 授予訓練進度
```

本文件不鎖死具體反刷公式。

---

## 12. 建議 D1 結構方向

九屬性修習：

```text
character_attribute_progress
├── character_id
├── attribute_type
├── rank
├── progress_exp
└── metadata
```

專精：

```text
character_specializations
├── character_id
├── specialization_type
├── progress_exp
├── mastery_stage
├── permanent_modifier_profile
└── metadata
```

能力／攻擊來源可帶成長標籤：

```text
progression_tags
├── primary_attribute
├── secondary_attribute nullable
└── specialization nullable
```

所有正式進度仍只保存於 D1。

---

## 13. Alpha 鎖定方向

1. 專精與九屬性修習相似，會透過實際有效使用累積進度。
2. 物理行動採雙軌修習：增加「物理屬性修習」以及「實際使用方式的專精修習」。
3. 使用劍會同時增加物理與劍類專精；使用錘會同時增加物理與錘類專精；徒手同理。
4. 一般元素魔法只增加對應元素修習，不另外為每個法術建立專精經驗。
5. 附魔魔法施放時增加其元素修習；其後的物理攻擊增加物理與對應武器專精，不因附魔存在而每擊額外增加元素修習。
6. 具名物理能力按實際攻擊來源決定專精成長項目，而不是每個招式自成一條經驗線。
7. 真正混合型能力可以由能力定義明確指定多個成長標籤；具體 EXP 分配比例留待 Alpha Build。
8. 專精的成長收益屬於永久／常駐成長，但不會自動授予具名能力。
9. 專精不預設成為所有武器使用資格；只有能力明確要求時才作為前置。
10. 每次有效使用可以增加進度，但有效使用定義、EXP 數值、反刷機制與成長曲線全部留待 Alpha Build 調整。
11. 九屬性修習、專精、能力取得與能力使用資格仍為彼此分離的系統。
12. 所有正式進度與專精資料保存於 D1。
