# Damage Result 傷害敘事強度 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：正／負 Damage Result 的敘事強度、20 點敘事差距上限、AI 傷害描述、次生效果建議。  
> 本文件與 `COMBAT_DAMAGE_MODEL_ALPHA.md` 一起使用；不改變既有 HP 扣減公式。

---

# 1. 核心原則

`Damage Result` 同時保留兩種用途：

```text
機械用途
→ Damage Result > 0 時，扣除同等 HP

敘事用途
→ 用 Damage Result 的正負、大小、傷害類型、防禦來源與情境
→ 描述這次命中到底有多輕微／嚴重／無效
```

機械數值不截斷，但敘事差距設上限。

---

# 2. 敘事差距最高只計到 ±20

Canonical Alpha：

```text
敘事差距值
= clamp(Damage Result, -20, +20)
```

這個 Clamp **只影響描述強度，不影響實際傷害或防禦差值。**

例如：

```text
Damage Result = +37
→ 實際造成 37 HP 傷害
→ 敘事差距值 = +20
→ 已達最高正向敘事強度
```

```text
Damage Result = -46
→ HP 不變
→ 原始防禦餘裕仍保存為 46
→ 敘事差距值 = -20
→ 已達最高防禦優勢描述
```

目的：避免 AI 因為極端大數字不停把描述無限放大。

---

# 3. 正 Damage Result 敘事尺度

Alpha 預設：

| 敘事差距值 | 建議層級 | 一般感覺 |
|---:|---|---|
| `+1` | 最低有效傷害 | 輕碰、擦傷、淺傷、短暫灼痛 |
| `+2 ~ +5` | 輕傷 | 有明確受擊，但傷勢有限 |
| `+6 ~ +10` | 明顯受創 | 攻擊已具實質威力 |
| `+11 ~ +15` | 重創 | 強烈衝擊、深傷、明顯穿透 |
| `+16 ~ +19` | 嚴重受創 | 大幅壓過防禦，傷勢非常明顯 |
| `+20` | 最高敘事強度 | 毀滅性／壓倒性打擊級描述 |

`+20` 代表「敘事尺度已到頂」，不是額外暴擊、額外傷害倍率或固定狀態效果。

其中 `Damage Result = +1` 永遠是最低有效傷害：

```text
斬擊 +1
→ 淺淺劃過／很小的傷口

鈍擊 +1
→ 輕微撞痛／小瘀傷

火焰 +1
→ 表面輕微灼傷

雷電 +1
→ 短暫刺麻／輕微電擊
```

---

# 4. 零與負 Damage Result 敘事尺度

```text
Damage Result = 0
→ 剛好完全擋住
```

Alpha 預設：

| 敘事差距值 | 建議層級 | 一般感覺 |
|---:|---|---|
| `-1 ~ -4` | 勉強擋住 | 幾乎突破，但最後被防下 |
| `-5 ~ -9` | 明確擋住 | 防禦有穩定優勢 |
| `-10 ~ -14` | 強力擋住 | 攻擊明顯不足以突破 |
| `-15 ~ -19` | 壓倒性防禦 | 攻擊幾乎無法撼動防護 |
| `-20` | 最高防禦優勢 | 完全被壓制／隔絕級描述 |

例如：

```text
-1
→ 刀鋒幾乎切入，但最後被護甲卡住。

-20
→ 攻擊撞上防護後幾乎沒有任何穿透跡象。
```

---

# 5. 實際 HP 與目標狀態仍可作背景資訊

敘事主尺度使用 `-20 ~ +20`，但 AI／GM 仍可參考：

```text
Current HP / Max HP
這一擊是否令 HP 歸零
傷害類型
目標材質／生理結構
防禦來源
裝備狀態
命中位置
環境
```

這些資料只令描述更合理，不改變 20 點敘事差距上限。

例如同樣 `+10`：

```text
打普通人類
→ 可以描述成明顯鈍傷／切傷

打石像
→ 可以描述成裂紋、碎屑或表面崩裂

打史萊姆
→ 可以描述成形體被打散／局部被切開
```

# 6. AI 的角色

AI 可收到：

```text
原始 Damage Result
敘事差距值（-20 ~ +20）
Current HP / Max HP
原始傷害
有效防禦
傷害類型
武器／能力／Damage Profile
防禦來源
目標材質／種族／身體結構
命中位置（如有）
環境
D100 是否為大成功／大失敗
既有狀態與裝備損傷
```

AI 可以提供 **1–3 個合理敘事／效果建議**。

例如：

```text
Damage Result = +1
斬擊 vs 普通人類
```

可建議：

```text
1. 劍鋒只留下一道很淺的傷口。
2. 攻擊擦過皮膚，造成短暫刺痛。
3. 刀刃僅切入表層，沒有形成深傷。
```

例如：

```text
Damage Result = +18
重錘 vs 輕型護甲
```

可建議：

```text
1. 重擊明顯壓過護甲，造成非常沉重的衝擊。
2. 護甲局部明顯變形；如耐久規則適用，可由 GM 決定是否進一步處理。
3. 目標被打得失去穩定姿勢；是否形成正式位移／狀態由 GM 決定。
```

---

# 7. 敘事強度不自動送額外機械效果

```text
高 Damage Result
≠ 自動 Debuff
≠ 自動擊退
≠ 自動破甲
≠ 自動裝備損壞
```

AI 可以把合理的次生結果列入 1–3 個建議，但：

```text
AI 建議
→ GM 接受／修改／拒絕
→ 如屬正式機械效果，再交由相應 Resolver 處理
```

Damage Result 的 `+20 / -20` 亦不是另一套大成功／大失敗。

---

# 8. 不需要每次普通攻擊都呼叫 AI

系統可先用 `-20 ~ +20` 尺度產生簡短預設描述。

AI 可在以下情況介入：

```text
GM 主動要求
敘事差距接近上限
D100 大成功／大失敗
特殊材質／怪物／護甲
可能有環境連鎖
可能涉及裝備破壞／位移／狀態
重要 Boss／劇情場景
```

---

# 9. Alpha 鎖定結論

1. Damage Result 機械值完整保存，不設 ±20 機械上限。
2. 敘事差距值使用 `clamp(Damage Result, -20, +20)`。
3. `Damage Result = +1` 是最低有效傷害，預設為非常輕微的受擊。
4. 正數越高，受擊描述越嚴重；`+20` 為最高敘事強度。
5. 負數越低，防禦優勢越明顯；`-20` 為最高防禦優勢描述。
6. 超過 ±20 的實際 Damage Result 仍完整保存，只是不再提高敘事層級。
7. AI 可提供 1–3 個合理敘事／效果建議。
8. AI 不得僅因高 Damage Result 自動增加額外機械效果。
9. 額外效果仍需 GM 接受並交由相應 Resolver 處理。
10. Damage Result 敘事尺度與 D100 大成功／大失敗保持分離。
