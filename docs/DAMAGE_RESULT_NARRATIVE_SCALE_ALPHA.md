# Damage Result 傷害敘事強度 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：正／負 Damage Result 的敘事強度、HP 比例、AI 傷害描述、次生效果建議。  
> 本文件與 `COMBAT_DAMAGE_MODEL_ALPHA.md` 一起使用；不改變既有 HP 扣減公式。

---

# 1. 核心原則

`Damage Result` 同時保留兩種用途：

```text
機械用途
→ Damage Result > 0 時，扣除同等 HP

敘事用途
→ 用 Damage Result 的正負、大小、佔目標 Max HP 比例與情境
→ 描述這次命中到底有多輕微／嚴重／無效
```

因此：

```text
Damage Result = +1
≠ 單純顯示「HP -1」就完結

Damage Result = -20
≠ 單純顯示「0 Damage」就完結
```

兩者都可以保留有意義的受擊描述。

---

# 2. 1 點傷害是最低有效傷害

Canonical Alpha：

```text
Damage Result = +1
→ 已經突破防禦
→ 造成 1 HP 傷害
→ 預設描述為非常輕微的有效受擊
```

例如：

```text
斬擊 +1
→ 淺淺劃過／留下很小的傷口

鈍擊 +1
→ 輕微撞擊／短暫疼痛／很輕的瘀傷

火焰 +1
→ 短暫灼到／表面輕微燙傷

雷電 +1
→ 一下輕微電擊／短暫刺麻
```

所以「1 Damage」不是 Miss，也不是完全被擋住；只是剛剛足以造成有效傷害。

若目標本身極度脆弱、Max HP 只有極低數值，或其 Profile 明確有特殊反應，GM／AI 仍可按實際世界狀態調整描述。

---

# 3. 正 Damage Result 的敘事強度

除 `+1` 的最低有效傷害外，較高 Damage Result 應參考它佔目標最大 HP 的比例。

概念：

```text
Damage Ratio
= Damage Result / 目標 Max HP
```

Alpha 建議敘事尺度：

| Damage Result / Max HP | 建議敘事層級 | 一般感覺 |
|---|---|---|
| `+1` | 輕微受擊 | 擦傷、輕碰、淺傷、短暫灼痛 |
| `>1` 且 `<=10%` | 輕傷 | 明確受傷，但影響有限 |
| `>10%–25%` | 明顯受創 | 攻擊有實質威力，目標明顯受到影響 |
| `>25%–50%` | 重創 | 強烈打擊、深傷、猛烈衝擊 |
| `>50%–75%` | 嚴重受創 | 大幅削弱目標，可能接近失去戰鬥能力 |
| `>75%` | 毀滅性打擊 | 極高程度傷害，可能直接改變戰局 |

以上是**敘事尺度**，不是額外傷害倍率。

例如：

```text
目標 Max HP = 20
Damage Result = +1
→ 1 HP
→ 輕微擦傷／淺傷
```

```text
目標 Max HP = 20
Damage Result = +4
→ 20%
→ 明顯受創
```

```text
目標 Max HP = 20
Damage Result = +10
→ 50%
→ 重創級打擊
```

```text
目標 Max HP = 20
Damage Result = +18
→ 90%
→ 毀滅性打擊
```

如果一次傷害足以令 Current HP 降至 0 或以下，系統可以額外標示：

```text
足以令目標 HP 歸零
```

但「HP 歸零之後是否死亡、昏迷、失去戰鬥能力或觸發其他狀態」由相應生命／倒地規則處理，不在本文件自動決定。

# 4. 負 Damage Result 同樣保留敘事價值

負數不造成 HP 傷害，但描述防禦有多大餘裕。

例如：

```text
Damage Result = -1
→ 勉強擋住
```

可能描述：

```text
刀鋒幾乎切入，但最後被護甲卡住。
護盾劇烈震動，仍成功擋下攻擊。
結界出現明顯波紋，但沒有被突破。
```

而：

```text
Damage Result = -20
→ 攻擊與防禦差距非常明顯
```

可能描述：

```text
武器撞上護甲後幾乎無法撼動對方。
火焰被結界完整吞沒，只留下短暫波紋。
攻擊像撞上一道厚牆，完全沒有穿透跡象。
```

負數本身不需要硬切成固定等級；AI／GM 可以同時參考：

```text
負 Damage Result 絕對值
原始傷害
有效防禦
防禦來源
傷害類型
材質／護甲／結界性質
```

去決定最自然的描述。

# 5. 傷害類型必須改變描述方式

相同 Damage Result 不應永遠使用同一句描述。

例如 `Damage Result = +4`：

```text
斬擊
→ 明顯切開皮膚／護甲縫隙

鈍擊
→ 沉重撞擊、瘀傷、震動

刺擊
→ 穿刺傷、局部深入

火焰
→ 灼傷、焦痕、高溫衝擊

雷電
→ 電擊、肌肉抽動、局部灼痕

冰／低溫類效果（如由能力產生）
→ 凍傷、結霜、局部僵硬
```

AI 應使用 Damage Profile 的傷害類型與目標材質／生理結構，而不是把所有傷害都描述成「流血」。

例如機械人、石像、幽靈、史萊姆等目標需要完全不同的受擊語言。

# 6. AI 的角色：把數值變成合理世界反應

AI 可收到：

```text
Damage Result
Damage Ratio
Current HP / Max HP
原始傷害
有效防禦
傷害類型
武器／能力／Damage Profile
防禦來源
目標材質／種族／身體結構
命中位置（如有）
環境
D100 是否為大成功／大失敗
既有狀態與裝備損傷
```

AI 可以提供 **1–3 個敘事／效果建議**。

例如：

```text
Damage Result = +1
傷害類型 = 斬擊
目標 = 普通人類
```

AI 可建議：

```text
1. 劍鋒只在手臂留下一道很淺的傷口。
2. 攻擊擦過皮膚，帶來短暫刺痛與少量出血。
3. 刀刃僅僅切入表層，沒有形成深傷。
```

例如：

```text
Damage Result = +10
Max HP = 20
傷害類型 = 鈍擊
目標穿輕甲
```

AI 可建議：

```text
1. 重擊壓過輕甲，目標被打得身形明顯一晃。
2. 護甲吸收部分衝擊，但仍留下沉重鈍傷。
3. 衝擊集中在胸側，足以令目標短暫呼吸紊亂；是否形成額外狀態由 GM 決定。
```

# 7. 敘事強度不自動送額外機械效果

非常重要：

```text
傷害描述很重
≠ 自動附送 Debuff
```

例如：

```text
Damage Result = +18
→ 可以描述成毀滅性重擊
```

但不代表系統自動增加：

```text
暈眩 3 回合
護甲永久 -5
擊退 10 米
骨折
流血 Debuff
```

如 AI 認為上述效果合理，可以列入 1–3 個建議，但：

```text
AI 建議
→ GM 接受／修改／拒絕
→ 如屬正式機械效果，再交由相應 Status／Equipment／Movement Resolver 處理
```

這避免 Damage Result 同時變成另一套隱藏 Ability 系統。

---

# 8. 不需要每次普通攻擊都呼叫 AI

普通 Damage Result 可以由系統先用尺度產生簡短預設描述。

例如：

```text
+1
→ 輕微受擊

+4 / Max HP 20
→ 明顯受創

-1
→ 勉強擋住

-20
→ 完全無法撼動防禦
```

AI 可在以下情況介入：

```text
GM 主動要求更完整描述
高 Damage Ratio
D100 大成功／大失敗
特殊材質／怪物／護甲
可能有環境連鎖
可能涉及裝備破壞／位移／狀態
重要 Boss／劇情場景
```

實際自動觸發門檻留待 Alpha 測試。

---

# 9. Alpha 鎖定結論

1. Damage Result 同時保存機械傷害與敘事強度資訊。
2. `Damage Result = +1` 是最低有效傷害，預設描述為非常輕微的受擊，而不是 Miss。
3. 正 Damage Result 除實際數值外，亦參考 `Damage Result / Max HP` 判斷敘事嚴重程度。
4. 負 Damage Result 不扣 HP，但其絕對值可描述防禦餘裕。
5. 傷害類型、目標材質／生理結構、防禦來源必須影響描述。
6. AI 可提供 1–3 個合理敘事／效果建議。
7. AI 不得因高 Damage Result 自動增加額外 Debuff、破甲、擊退或其他機械效果。
8. 額外機械效果仍需 GM 接受並交由相應 Resolver 處理。
9. Damage Result 敘事尺度不是 D100 大成功／大失敗的替代品。
10. 普通攻擊可使用系統預設描述，不要求每次都呼叫 AI。
