# 物理專精防雙重膨脹規則 — Alpha

> 狀態：Canonical Alpha Override
> 範圍：物理修習、武器專精修習、成長獎勵分配、物理階級、專精永久增益、混合能力。
> 目的：避免物理角色因同時擁有「物理」與「武器專精」兩條成長線，在高階段產生雙重數值膨脹。

---

## 1. 核心原則：雙軌成長，不代表雙重倍率

角色可以同時累積：

```text
物理修習
+
對應武器／戰鬥方式專精修習
```

例如：

```text
使用劍類物理行動
→ 物理修習
→ 劍類專精修習
```

但這兩條成長線不得在戰鬥中變成兩個獨立、可無限制相乘／相加的威力來源。

Canonical：

```text
雙軌修習
≠
雙重傷害倍率
```

---

## 2. 每次有效行動只有一份「總修習權重」

為避免物理行動比魔法行動多拿一倍成長量，每次有效行動只產生一份總修習權重。

概念例：

```text
使用火魔法
→ 火屬性修習：100%
```

```text
使用劍類物理行動
→ 物理修習：50%
→ 劍類專精修習：50%
```

上述 `50% / 50%` 只代表 Alpha 可採用的比例概念，不是最終鎖死數值。

Alpha Build 可再測試：

```text
50 / 50
60 / 40
70 / 30
其他比例
```

但必須維持：

```text
同一次普通行動的總修習獎勵 ≈ 一份完整修習獎勵
```

不可因為同時寫入兩條進度，就實際得到兩倍總成長。

---

## 3. 物理階級不提供第二套直接傷害加成

物理階級的主要職責是：

```text
決定角色可以正常駕馭多高階的物理能力
提供物理能力的整體威力／控制上限
作為 AI Ability Scale 的角色能力上限參考
```

物理階級本身**不應再額外提供一條可與專精疊加的無上限傷害倍率**。

例如不採用：

```text
物理五階：傷害 +25%
劍專精五階：傷害 +25%
最後直接 +50%
```

更不採用：

```text
物理倍率 × 劍專精倍率
```

這會造成高階物理角色雙重膨脹。

---

## 4. 專精是條件式永久增益，但必須受共同上限限制

劍類、錘類、徒手、槍／矛等專精仍可視為角色的永久成長／常駐增益。

但專精效果應以「有限、條件式、受上限約束」為原則。

可提供：

```text
判定穩定度
來源加值
降低特定武器懲罰
特定招式控制能力
反擊／格擋／破防等專屬效果
有限傷害修正
特定能力效率
特定條件下的資源效率
其他武器風格特性
```

不應把專精設計成另一條無限線性傷害成長。

---

## 5. 單次能力只有一份總威力預算

無論角色同時符合多少成長來源，一個物理能力仍然只有一份 Rank／Reference Power Budget。

例如：

```text
物理五階
劍類專精很高
使用五階劍技
```

不代表：

```text
五階物理預算
+
五階劍專精預算
=
十階等價輸出
```

正確概念：

```text
五階物理能力預算
↓
劍類專精在該預算框架內提供有限效率／穩定度／條件式修正
```

專精可以令角色「更擅長用劍」，但不能把同一個五階能力變成超出五階總威力尺度的大幅度輸出。

---

## 6. 專精修正不得與同類物理修正無限制疊加

若未來系統加入其他永久物理熟練修正，Alpha 預設使用共同修正上限。

同一分類中的永久修正不得無限制累加。

概念上可採：

```text
最終專精修正
= min(
    所有適用永久專精修正總和,
    該物理階級允許的專精修正上限
  )
```

實際上限數值留待 Alpha Build 測試。

亦可在 Alpha Test 後改為「取最高」、「分組上限」或其他更合適模型，但 Canonical 原則不變：

> 專精不能形成第二條無上限威力曲線。

---

## 7. 專精應優先提供「風格差異」而非純傷害

為降低後期數值膨脹，專精成長應優先表現角色的武器風格，而不是單純增加傷害。

例如：

```text
劍類專精
→ 更穩定的反擊
→ 某些劍技來源加值
→ 降低多段斬擊控制懲罰
→ 有限傷害修正
```

```text
錘類專精
→ 擊退／破防效果更穩定
→ 對重型攻擊的控制能力提升
→ 有限傷害修正
```

```text
徒手專精
→ 擒抱／反制／連擊控制改善
→ 特定徒手能力效率提升
→ 有限傷害修正
```

因此兩名同為物理五階的角色可以有明顯不同風格，但不需要其中一方因為多一條專精曲線而在純數值上全面碾壓另一方。

---

## 8. 魔法維持單屬性修習

普通單元素魔法通常只增加對應元素修習。

例如：

```text
火球術
→ 火屬性修習
```

```text
雷擊術
→ 雷屬性修習
```

魔法不因沒有第二條武器專精而吃虧，因為物理的雙軌修習本身已經共享同一份總修習權重，而且戰鬥輸出仍受同一份能力威力預算約束。

---

## 9. 混合能力仍只有一份總修習獎勵

真正同時要求物理操作與元素操控的混合能力，可以把同一次修習獎勵分配到多條相關軌道。

例如：

```text
炎龍劍式
```

可能涉及：

```text
物理
火
劍類專精
```

但一次有效使用仍只有一份總修習權重，例如 Alpha 概念：

```text
物理：40%
火：30%
劍類專精：30%
```

具體比例由能力定義／Alpha Build 決定。

不得變成：

```text
物理 +1
火 +1
劍專精 +1
```

令一次行動等同三次完整修習。

---

## 10. 混合能力戰鬥計算亦只有一份總威力預算

即使一個能力同時涉及：

```text
物理
火
劍類專精
```

它仍然是一個能力定義，只有一份 AI／GM 批准的總 Power Budget。

不同來源只影響：

```text
是否符合使用條件
能力如何分配物理／元素輸出
哪些專精修正可以適用
控制複雜度
來源加值
其他條件式效果
```

不得將三條成長線各自的完整威力預算全部疊加。

---

## 11. Alpha Build 留待調整的數值

以下全部留待 Alpha Build／Alpha Test：

```text
物理 vs 專精的修習分配比例
專精每階／每段需要多少修習 EXP
專精是否採 0–9 階、百分比、段位或其他顯示方式
各物理階級允許的專精永久修正上限
不同專精可以提供多少來源加值／傷害修正
混合能力的三軌修習分配比例
高階專精的遞減收益曲線
```

但不得推翻本文件的核心原則：

```text
一個行動 = 一份總修習權重
一個能力 = 一份總威力預算
```

---

## 12. Alpha 鎖定方向

1. 物理可以同時累積「物理修習」與「武器／戰鬥方式專精修習」。
2. 同一次普通行動只產生一份總修習權重；雙軌只代表分配，不代表雙倍 EXP。
3. 普通單元素魔法通常把完整修習權重放入對應元素。
4. 物理階級主要決定能力階級／威力框架，不再提供一條可與專精無限制疊加的直接傷害倍率。
5. 專精屬於條件式永久增益，但必須受共同上限／Power Budget 約束。
6. 專精應優先提供風格、穩定度、來源加值、控制與有限效率，而不是純線性傷害膨脹。
7. 一個物理能力只有一份總威力預算；物理階級與專精不能各自提供完整一份威力預算。
8. 真正混合能力可以同時累積物理、元素與專精修習，但仍只分配一份總修習權重。
9. 混合能力戰鬥時仍只有一份總威力預算，不可把多條成長線的完整威力直接相加。
10. 所有比例、修正上限與高階曲線留待 Alpha Build／Alpha Test 調整。
11. 所有正式成長、專精與修習資料仍保存於 D1。
