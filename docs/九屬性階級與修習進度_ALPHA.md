# 九屬性階級與修習進度 — Alpha

> 狀態：Canonical Alpha Direction
> 範圍：物理、光、暗、火、水、風、土、雷、木九種屬性的階級、修習進度、能力使用資格。

---

## 1. 核心方向

每個角色對九種屬性分別擁有：

```text
屬性階級
修習進度
```

例如：

```text
物理：4階
修習進度：62 / 下一階需求

火：2階
修習進度：43 / 下一階需求
```

其中：

- 屬性階級代表角色目前能夠實際駕馭的能力階級上限之一；
- 修習進度代表角色在該屬性上的成長累積；
- 能力是否已取得與是否可使用維持分離。

---

## 2. 九種屬性

正式屬性：

```text
物理
光
暗
火
水
風
土
雷
木
```

每個屬性可由 0 階開始：

```text
0階 = 尚未入門／未具備正常使用資格
1階～9階 = 對應能力 Scale / Reference Table 的階級
```

角色可以已經取得高於自己目前屬性階級的能力，但該能力會顯示為「已取得・不可使用」。

---

## 3. 能力使用的基本階級檢查

例如：

```text
角色火屬性：1階
火球術：1階
→ 通過屬性階級檢查
```

```text
角色火屬性：1階
末日：9階
→ 已取得仍可存在
→ 目前不可使用
```

最基本規則：

```text
角色對應屬性階級 >= 能力階級
→ 通過階級使用條件

角色對應屬性階級 < 能力階級
→ 已取得但目前不可使用
```

能力仍可另外要求其他特殊條件。

---

## 4. 修習進度不是一般角色 EXP

角色總體 EXP／Level 與九屬性修習進度是不同系統。

```text
角色 EXP
→ 決定角色 Level

屬性修習進度
→ 決定某一屬性距離下一階有多近
```

角色升 Level 不會自動令所有屬性升階。

---

## 5. 修習進度來源

修習進度應來自有意義的遊戲內成長，而不是單純重複刷同一能力。

可能來源包括：

```text
實戰中的有效使用
正式訓練
導師／師傅指導
學校／學院／門派課程
研究與修習
特殊物品／材料
任務／劇情
戰鬥突破
GM獎勵
其他 Campaign 定義來源
```

不建議：

```text
每施放一次火球術固定 +1
```

以避免玩家透過無意義重複行為刷滿修習進度。

---

## 6. 物理屬性同樣使用此模型

物理不再拆成劍術、刀術、錘術、徒手等多條 0–99 技能值。

例如：

```text
物理：5階
```

代表角色的整體物理能力階級。

劍、錘、徒手、槍／矛等差異主要由：

```text
武器／攻擊來源本身
已取得的物理能力
常駐專精／永久增益
其他增益／減益
```

表現。

因此兩個角色都可以是物理 5 階，但因為擁有不同的專精、能力與裝備而呈現完全不同的戰鬥風格。

---

## 7. 專精與屬性階級分離

專精維持既有規則：

```text
專精 = 常駐增益
```

例如：

```text
劍類專精
錘類專精
徒手專精
```

專精不等同屬性階級，也不直接改寫角色最高可用能力階級，除非個別能力明確把某專精列為前置條件。

---

## 8. 每階需要多少修習 EXP 留待 Alpha Build 決定

目前只鎖定：

```text
每個屬性有獨立的修習進度
修習進度用於升階
0～9階
能力階級與屬性階級對應
```

暫時不鎖定：

```text
1階 → 2階需要多少修習 EXP
2階 → 3階需要多少修習 EXP
高階是否需要非線性增加
是否存在額外突破門檻
是否滿進度後自動升階或需要 GM／劇情確認
```

以上數值與曲線於 Alpha Build 中實際測試後調整。

實作上應保持可配置，不要把單一數字硬編碼成不可調整規則。

---

## 9. 玩家能力頁顯示

玩家端可在能力頁／角色狀態頁看到：

```text
物理    4階    修習 62 / ?
光      0階    修習 0 / ?
暗      1階    修習 21 / ?
火      3階    修習 78 / ?
水      0階    修習 0 / ?
風      2階    修習 34 / ?
土      0階    修習 0 / ?
雷      1階    修習 12 / ?
木      0階    修習 0 / ?
```

在 Alpha Build 正式決定各階需求後，`?` 才替換成實際需求值／進度條。

---

## 10. D1 原則

所有正式屬性階級與修習進度必須保存於 D1。

概念資料：

```text
character_element_progression
├── character_id
├── element_type
├── rank
├── progression_exp
├── updated_at
└── metadata
```

每階 EXP 需求應由 Campaign／規則設定表提供，而不是由角色紀錄本身硬寫死。

---

## 11. Alpha 鎖定方向

1. 九種屬性分別擁有獨立階級與修習進度。
2. 0階代表未入門；1～9階對應 Ability Scale / Reference Rank。
3. 屬性階級控制能力使用資格之一，但不控制能力是否可以被取得／擁有。
4. 角色可以擁有目前不可使用的高階能力。
5. 角色總 EXP／Level 與屬性修習進度分離。
6. 屬性升階不因角色升級而自動發生。
7. 修習進度應來自有意義的訓練、實戰、導師、研究、劇情、GM獎勵等來源。
8. 不採用可被無限重複刷取的單次施放固定加經驗機制。
9. 物理與八種魔法屬性使用同一階級／修習框架。
10. 劍、錘、徒手等差異由能力、來源與常駐專精表現，不另外拆成多條核心技能值。
11. 每階實際所需修習 EXP、曲線、突破條件留待 Alpha Build 調整。
12. 所有正式資料只保存於 D1。
