# Currency Exchange UI Override

> Status: Canonical UI correction for Alpha.
> Scope: supersedes any earlier mockup/spec text that shows two separate randomisation buttons.

GM General Control Panel must expose only one randomisation control:

```text
[Randomise Today's Rates]
[Save as Current Rates]
```

Pressing `Randomise Today's Rates` again simply replaces the current unsaved DRAFT with a newly generated DRAFT.

Do **not** add a separate `Randomise Again` button.
