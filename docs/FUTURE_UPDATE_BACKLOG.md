# A. 混合招式系統

**狀態：DEFERRED**

## 目前決定

混合招式暫時不作為目前 Alpha 核心規則的一部分。

目前 Alpha 先維持：

- 魔法能力主要由對應元素階級／修習處理；
- 物理能力主要由對應武器專精處理；
- `物理` 保留作能力／傷害分類，不再作獨立角色成長軸；
- 不建立 `物理倍率 × 武器專精倍率` 的雙重成長乘法；
- 不因少數混合招式而改動目前整套成長架構。

## 未來需要處理

### A1. 多來源標示

例如：

```text
炎龍劍式
├─ 武器系：劍
├─ 元素：火
└─ 類型：混合招式
```

需決定：

- 多個平等來源；或
- 主要來源／次要來源。

### A2. 使用資格

需要決定混合招式是否要求：

```text
劍類專精 ≥ X
且
火元素階級 ≥ Y
```

或其他主次條件／最低條件模型。

### A3. 修習 EXP 分配

一次使用只可產生一份總修習預算。

可於未來測試例如：

```text
劍類專精 60%
火元素 40%
```

實際權重不得在現階段寫死。

### A4. 威力計算

禁止：

```text
完整劍專精倍率 × 完整火元素倍率
```

亦禁止：

```text
完整物理預算 + 完整火元素預算
```

一個混合招式只可有一份總威力 Budget。

未來可研究：

- 主來源提供基礎框架，次來源改變效果；
- 總 Budget 按來源比例分配；
- AI Reference/Scale 直接生成單一混合 Profile。

### A5. 武器與元素責任分工

例如炎龍劍式可考慮：

- 劍類專精：命中、操控、連擊、反擊、武器技巧；
- 火元素：火焰傷害、燃燒、元素效果；
- 不允許兩者各自完整放大同一項輸出。

### A6. 混合招式階級

需研究是否採單一能力階級：

```text
炎龍劍式：五階
```

另外保存學習／使用條件：

```text
劍類專精 ≥ 4
火元素 ≥ 3
```

而不是把同一招拆成兩個完整階級倍率。

### A7. AI 判斷

未來 AI 應能分辨：

```text
純武器技
純元素魔法
附魔
真正混合招式
```

語意不明時沿用 AI 歧義澄清模式。

### A8. 附魔與混合招式分離

```text
火焰附魔 + 普通劍擊
≠
炎龍劍式
```

前者為攻擊來源 + Buff；後者為能力本身同時要求兩種操控來源。

### A9. 三重以上來源

未來可能出現：

```text
劍 + 火 + 風
雙武器 + 雷
徒手 + 土
```

需考慮：

- 最大來源數；
- 遞減收益；
- 總威力 Budget；
- 修習 EXP 總量限制。

### A10. UI

未來能力頁可顯示：

```text
炎龍劍式
混合招式
劍類 / 火
五階
```

暫不建立獨立「混合」主分頁。

## 不可違反原則

1. 一次使用只產生一份總修習預算。
2. 一個能力只使用一份總威力預算。
3. 不允許多個完整倍率互乘造成後期爆炸。
4. 附魔攻擊與真正混合招式必須分開。

# B. 元素／武器專精修習 EXP 曲線

**狀態：ALPHA_TUNING**

目前只鎖定存在獨立修習進度；實際數字留待 Alpha。

未來需測試：

- 每階需要多少修習 EXP；
- 高階是否使用非線性需求；
- 0→1 與 8→9 的成長差距；
- 實際使用、正式訓練、導師教學、劇情獎勵各自的 EXP 權重；
- 防止重複施法／重複揮武器刷 EXP；
- 是否需要每日／場景／戰鬥軟上限；
- 滿 EXP 後是否直接升階或需要突破條件。

# C. 武器專精成長與獎勵曲線

**狀態：ALPHA_TUNING**

目前決定：

- 物理不再有獨立角色總階級；
- 劍、槍／矛、錘、徒手等武器／戰鬥方式可各自成長；
- 專一使用自然獲得更高深度；
- 玩家可以多修，但不額外禁止。

未來需測試：

- 各專精階級／稱號；
- 升階需要多少 EXP；
- 專精提供哪些永久優勢；
- 傷害、命中、控制、反擊、破防等 Bonus 如何避免後期膨脹；
- 是否需要遞減收益；
- 是否容許極高專精突破一般效果上限；
- 單武器專精的獎勵是否足夠鼓勵專一玩法。

# H. Character Level 升級技能點

**狀態：ALPHA_TUNING**

目前已鎖定：

- Character EXP → Level 保留；
- Level-up 可授予技能點（SP）；
- SP 主要用於提升 22 個基礎技能；
- SP 不直接購買／解鎖具名能力；
- 基礎技能另可透過有效 D100 判定的大成功產生使用成長。

未來只需調整：

- 每級實際授予多少 SP；
- SP 是否 `1 SP = +1`；
- 高技能區間是否提高 SP 成本；
- Creation SP 與 Level-up SP 是否使用完全相同的消耗曲線；
- 多級一次跨越時如何補發。

工作簿的 +5／Level 僅作參考，不視為最終數值。

# K. 基礎技能大成功成長曲線

**狀態：ALPHA_TUNING**

目前已鎖定：

- 基礎技能採 `SP + 使用成長`；
- 使用成長只在有效 D100 判定取得大成功時觸發；
- 大成功先產生成長進度／標記，不直接令技能值 +1；
- 普通成功、失敗、大失敗不產生使用成長；
- 無意義刷骰不產生成長。

未來 Alpha 需測試：

- 一次大成功提供多少成長進度；
- 多少成長進度換取 +1 技能值；
- 高技能區間是否需要更多成長進度；
- 是否需要每場景／每 Session 的同技能成長軟上限；
- SP 成長與大成功成長同時存在時的總成長速度；
- 最高技能值附近的遞減收益／硬上限；
- 統一 D100 骰點結果系統對「大成功」的精確門檻。

# Future Update 全域原則

1. Future idea 不得因為尚未完成而偷偷影響目前 Alpha Canonical 規則。
2. 所有數值曲線盡量做成可配置，避免寫死後難以 Alpha 調整。
3. D1 仍為唯一持久資料來源。
4. 玩家／GM 可見內容使用繁體中文。
5. AI 建議不是最終權威；GM 可調整 AI 提供數值。
6. Future Update 一律集中更新本文件，不再拆新 Future Update 文件。
