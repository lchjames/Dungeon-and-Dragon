# 移除物理總階級，改用武器專精成長 — Alpha

> 狀態：Canonical Alpha Override  
> 範圍：物理能力、武器專精、物理成長、能力使用資格、玩家能力頁。  
> 本文件覆蓋較早文件中「物理作為角色獨立 0–9 階成長軸，再與劍／錘／徒手專精共同計算」的描述。

---

## 1. 核心修正

角色不再擁有一條獨立的：

```text
物理階級
物理修習 EXP
物理倍率
```

`物理`仍然保留作為：

```text
能力分類
傷害／來源分類
Reference / Scale 平衡分類
玩家能力頁的大分類
```

但它不再是一條角色本身的獨立成長軸。

角色的物理成長直接落在實際使用的武器／戰鬥方式專精上。

---

## 2. 魔法與物理使用不同的成長結構

### 魔法

八種元素各自擁有自己的修習進度與階級：

```text
光
暗
火
水
風
土
雷
木
```

例如：

```text
火：3 階
火修習 EXP：...
```

使用火系魔法主要推進火系修習。

### 物理

物理不再有共同的「物理階級」。

改為由武器／戰鬥方式本身承擔成長，例如：

```text
劍類專精
槍／矛類專精
錘類專精
斧類專精
弓類專精
徒手專精
其他 Campaign 定義的物理專精
```

每個專精可以有自己的：

```text
階級
修習 EXP
成長紀錄
```

精確 EXP 曲線、階級門檻與數值效果留待 Alpha Build 調整。

---

## 3. 物理能力的使用資格直接引用對應專精

例如：

```text
月牙斬
類型：物理
武器系：劍
能力階級：3
```

其主要物理修習條件可以是：

```text
劍類專精 >= 3 階
```

而不是：

```text
物理 >= 3 階
+
劍類專精 >= 某值
```

因此取消原本兩條成長線同時參與物理能力威力／資格的問題。

同理：

```text
震地重擊
類型：物理
武器系：錘
能力階級：4

主要條件：錘類專精 >= 4 階
```

```text
崩拳
類型：物理
武器系：徒手
能力階級：2

主要條件：徒手專精 >= 2 階
```

能力仍可有其他獨立前置，例如屬性、裝備、姿態、劇情條件等。

---

## 4. 專精本身成為主要物理 Scaling，而不是第二層 Scaling

取消：

```text
物理倍率 × 劍專精倍率
```

也取消：

```text
物理階級加成 + 劍專精加成
```

新的基本概念是：

```text
劍類能力
→ 直接使用劍類專精對應的物理 Scale
```

```text
錘類能力
→ 直接使用錘類專精對應的物理 Scale
```

因此武器專精本身不會被弱化，因為它已經由「附加成長」提升為「物理成長的主要軸」。

---

## 5. 單武器專精會自然得到回報

系統不需要硬性禁止角色同時練多種武器。

角色可以同時擁有：

```text
劍類專精
槍／矛類專精
徒手專精
```

但每條專精有自己的修習進度。

例如：

```text
使用劍
→ 劍類專精獲得修習
```

```text
使用槍／矛
→ 槍／矛類專精獲得修習
```

因此角色若長期只使用劍，其大部分物理修習自然集中在劍類專精；若同時分散使用劍、槍、錘，修習時間亦自然被分散。

所以：

```text
專注單一武器
→ 同一條專精成長較快／較深

同時修習多武器
→ 戰術選擇較多，但各條專精成長較分散
```

這是自然的 Opportunity Cost，不需要額外加入「多修武器懲罰」。

---

## 6. 一次物理行動只推進實際使用的專精

較早的：

```text
使用劍
→ 物理修習 + 50%
→ 劍專精 + 50%
```

取消。

改為：

```text
使用劍
→ 劍類專精修習 + 100% 對應權重
```

```text
使用錘
→ 錘類專精修習 + 100% 對應權重
```

```text
徒手攻擊
→ 徒手專精修習 + 100% 對應權重
```

實際每次行動給多少 EXP、是否每次使用都給、反刷機制、訓練／戰鬥／劇情修習權重，留到 Alpha Build 平衡。

---

## 7. 混合能力仍可同時推進「武器專精 + 元素」

例如：

```text
炎龍劍式
類型：混合
物理來源：劍
元素：火
```

它可以同時推進：

```text
劍類專精
+
火元素修習
```

但一次能力仍只有一份總修習預算。

例如概念上可以拆成：

```text
劍類專精 60%
火元素 40%
```

比例不是 Canonical 數值，留到 Alpha Build 調整。

戰鬥威力同樣只允許一份總 Power Budget，不會把完整劍系倍率與完整火系倍率相乘。

---

## 8. 玩家能力頁的呈現

`物理`可以繼續作為能力頁的大分類，但不顯示「物理階級」。

例如：

```text
物理

劍類專精：4 階
├─ 月牙斬
├─ 反擊劍式
└─ 破風斬

錘類專精：1 階
└─ 震地擊（已取得・目前不可使用：需要錘類專精 3 階）

徒手專精：2 階
├─ 崩拳
└─ 擒拿
```

魔法則仍按元素顯示：

```text
火：3 階
├─ 火球術
├─ 火焰附魔
└─ 末日（已取得・不可使用）
```

---

## 9. 「物理」仍是能力屬性／類型，但不是角色進度條

技術上可以繼續保留：

```text
ability_type = PHYSICAL
```

用於：

```text
Reference / Scale Table
傷害分類
AI 能力生成
能力頁篩選
規則解析
```

但角色不再需要：

```text
character_physical_rank
character_physical_exp
```

物理能力改為引用：

```text
required_mastery_type
required_mastery_rank
```

例如：

```text
required_mastery_type = SWORD
required_mastery_rank = 3
```

---

## 10. Alpha 鎖定方向

1. 移除角色獨立「物理階級／物理 EXP／物理倍率」成長軸。
2. `物理`保留為能力、傷害、Reference/Scale 與 UI 分類。
3. 物理角色成長直接由武器／戰鬥方式專精承擔。
4. 劍、槍／矛、錘、徒手等專精各自有獨立階級與修習進度。
5. 物理能力的主要階級要求直接引用對應武器專精，不再同時要求另一條物理階級。
6. 專精本身成為主要物理 Scaling，不是疊在物理 Scaling 上的第二個倍率。
7. 一次普通物理使用只推進實際使用的武器專精，不再拆分一半給物理、一半給武器。
8. 角色可以修習多種武器，但修習進度自然分散；單一武器專精因集中使用而自然得到較深成長。
9. 不預設加入多武器懲罰；Opportunity Cost 由各專精獨立修習自然形成。
10. 混合物理＋元素能力可以同時推進武器專精與元素，但總修習與總威力仍受單一 Budget 約束。
11. 精確 EXP 門檻、階級曲線、專精倍率／效果與混合比例留待 Alpha Build 平衡。
12. 所有正式資料保存於 D1。
