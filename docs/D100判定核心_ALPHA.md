# D100 判定核心 — Alpha

> 狀態：Canonical Alpha Working Rule
> 範圍：D100 擲骰方向、天然技能值轉換、GM 成功／失敗界線、成功／失敗程度。

---

## 1. 骰點方向

D100 採用「高骰較好」方向：

```text
1   = 大失敗
100 = 大成功
```

現階段只鎖定兩個極端結果。

普通成功、普通失敗以及其他可能的結果分級，其界線暫由 GM／判定情境決定，不在本階段寫死固定區間。

---

## 2. 天然技能值與最低成功骰點

角色表上的百分比技能仍然表示角色的天然成功能力，天然永久值最高 98%。

由於骰點方向為「高骰較好」，不能直接使用傳統 roll-under 的 `骰點 <= 技能值`。

將技能值轉換為最低成功骰點：

```text
最低成功骰點 = 101 - 技能值
```

例：

```text
技能值 70
最低成功骰點 = 31

自然情況下：31–100 成功
共有 70 個成功結果
```

技能值 98 時：

```text
最低成功骰點 = 3

自然情況下：
1–2   位於失敗側
3–100 位於成功側
```

因此 98% 天然上限仍然保留兩格天然失敗空間。

---

## 3. 成功／失敗差值

為保留「負數代表成功，正數代表失敗程度」的直觀表示，定義：

```text
判定差值 = 最低成功骰點 - 有效骰點
```

判讀：

```text
判定差值 < 0
→ 成功
→ 絕對值越大，代表成功餘裕越高

判定差值 = 0
→ 剛好達標，視為成功

判定差值 > 0
→ 失敗
→ 數值越大，代表差得越遠
```

例：技能值 70：

```text
最低成功骰點 = 31
```

骰出 80：

```text
31 - 80 = -49
→ 成功
→ 成功餘裕 49
```

骰出 35：

```text
31 - 35 = -4
→ 成功
→ 僅高於門檻 4
```

骰出 20：

```text
31 - 20 = +11
→ 失敗
→ 差 11
```

這個差值可供 GM／後續系統判斷「成功得幾好」或「失敗得幾嚴重」。

---

## 4. GM 定義成功／失敗範圍

現階段不建立固定的普通／困難／極難成功表。

GM 可以按情境調整最低成功骰點，或直接設定該次判定的有效成功門檻。

概念：

```text
基礎最低成功骰點
+ GM 難度修正
= 該次判定最低成功骰點
```

較困難的行動可提高最低成功骰點；較容易的行動可降低最低成功骰點。

精確難度修正數值留待 Alpha 測試。

---

## 5. 裝備／能力／Buff 可以改變實際骰點結果

98% 是角色表天然技能值上限，不是最終判定硬上限。

稀有物品、能力、Buff、狀態或其他特殊效果，可以在判定時計入額外值。

概念：

```text
有效骰點
= 原始 D100 骰點
+ 正面判定加值
- 負面判定修正
```

然後：

```text
判定差值
= 最低成功骰點 - 有效骰點
```

因此一個原本位於失敗側的骰點，可以因稀有裝備／能力／Buff 而被推入成功側。

例：

```text
最低成功骰點 = 31
原始骰點 = 28
原本：31 - 28 = +3 → 失敗

特殊能力提供 +5 有效骰點
有效骰點 = 33
31 - 33 = -2 → 成功
```

---

## 6. 原始 1／100 與特殊修正的關係

目前只鎖定：

```text
原始骰點 1   = 大失敗
原始骰點 100 = 大成功
```

但以下細節暫不在本文件鎖死：

- 一般加值是否可把原始 1 的大失敗救回；
- 只有特殊標註效果才可改寫大失敗；
- 原始 100 的大成功是否可被極端負面修正降級；
- 大失敗／大成功與最終判定差值的優先級。

以上留待 D100 Resolver 下一階段決定。

---

## 7. Alpha 核心結論

1. D100 採高骰較好：1 大失敗、100 大成功。
2. 百分比技能值 S 轉換為 `最低成功骰點 = 101 - S`。
3. 天然技能值最高 98%，因此自然情況下至少保留兩格失敗側骰點。
4. `判定差值 = 最低成功骰點 - 有效骰點`。
5. 判定差值 <= 0 為成功；> 0 為失敗。
6. 正數可直接表示失敗差距；負數絕對值可表示成功餘裕。
7. GM 現階段可按情境定義／調整成功與失敗門檻。
8. 裝備、能力、Buff 等可改變有效骰點，並可把一般失敗推成成功。
9. 大失敗／大成功與特殊修正的最終優先級留待下一階段處理。
