# D100 判定核心 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：D100 擲骰方向、單一判定公式、技能值、Buff／裝備／能力／GM 修正、成敗差值。

---

## 1. 骰點方向

D100 採用「高骰較好」方向：

```text
1   = 大失敗
100 = 大成功
```

現階段先鎖定兩個極端骰面。

普通成功／失敗不使用另一套判定方法，而全部由同一條公式處理。

---

## 2. 唯一核心公式

Canonical：

```text
判定結果
= 骰點 - (100 - 技能值) + 總修正
```

其中：

```text
骰點      = 原始 D100 結果
技能值    = 角色表上的百分比技能值，天然最高 98
總修正    = Buff、Debuff、裝備、能力、GM 難度、環境等所有判定修正的總和
```

修正方向：

```text
正數 = 有利
負數 = 不利
```

不需要另外先計算「最低成功骰點」再做第二次運算；`(100 - 技能值)` 只是公式中的一部分。

---

## 3. 成敗判讀

```text
判定結果 > 0
→ 成功

判定結果 = 0
→ 失敗，剛好差 1 個有效點進入成功區

判定結果 < 0
→ 失敗
```

因此：

```text
正數越大
→ 成功餘裕越高

負數絕對值越大
→ 失敗程度越嚴重
```

這個最終數字同時負責「有沒有成功」與「成功／失敗得幾多」，不需要第二套 Margin 計算。

---

## 4. 基本例子

技能值：70

```text
100 - 70 = 30
```

### 骰 80

```text
80 - 30 = +50
→ 成功
```

### 骰 35

```text
35 - 30 = +5
→ 成功
```

### 骰 30

```text
30 - 30 = 0
→ 失敗
```

### 骰 20

```text
20 - 30 = -10
→ 失敗 10
```

因此技能值 70 在沒有修正時自然成功區間為：

```text
31–100
```

正好共有 70 個成功骰面。

---

## 5. 98% 天然技能值上限

角色表上的百分比技能天然永久值最高為 98%。

技能值 98：

```text
100 - 98 = 2
```

自然無修正時：

```text
骰 1：1 - 2 = -1 → 大失敗
骰 2：2 - 2 = 0  → 失敗
骰 3：3 - 2 = +1 → 成功
...
骰 100              → 大成功
```

因此天然角色表永遠保留至少兩個失敗側骰面。

98% 只限制角色表天然永久值，不限制最終判定結果可以被特殊效果推高。

---

## 6. Buff／裝備／能力直接加入同一條公式

例：

```text
技能值 = 70
骰點 = 28
稀有能力 = +5
```

計算：

```text
28 - (100 - 70) + 5
= 28 - 30 + 5
= +3
→ 成功
```

如果沒有能力：

```text
28 - 30
= -2
→ 失敗
```

因此特殊物品／能力可以將原本失敗的判定救成成功。

不需要改寫角色表技能值。

---

## 7. GM 難度亦只屬於「總修正」

現階段 GM 可以自行決定該次判定的難易度，但不要建立第二套公式。

例如：

```text
一般情況：GM 修正 +0
有利情況：GM 修正 +10
困難情況：GM 修正 -20
```

則全部仍使用：

```text
判定結果
= 骰點 - (100 - 技能值) + 總修正
```

`總修正` 可以概念上寫成：

```text
總修正
= Buff
+ 裝備
+ 能力
+ GM／環境修正
+ 其他有效來源
```

但在 Resolver 中最後只需要一個合計值。

---

## 8. 為何不用「骰點 - 技能值」

如果直接使用：

```text
骰點 - 技能值
```

技能值 70 時，要得到正數便需要骰出 71–100，只有 30% 成功率。

這會把 `70% 技能值` 反轉成約 `30% 成功率`，與角色表百分比的語義相反。

因此在「高骰較好」系統中，正確使用：

```text
骰點 - (100 - 技能值)
```

再加入總修正。

---

## 9. 原始 1／100 與特殊修正

目前鎖定：

```text
原始骰點 1   = 大失敗
原始骰點 100 = 大成功
```

但以下細節仍未鎖死：

- 大失敗是否能被普通修正救回；
- 是否只有明確寫明的稀有效果才可改寫大失敗；
- 大成功是否可能被特殊負面效果降級；
- 大成功／大失敗與最終公式結果的優先級。

這些留待正式 D100 特殊結果規則處理。

---

# Alpha 鎖定結論

1. D100 高骰較好：原始 1 大失敗、原始 100 大成功。
2. 百分比技能天然永久值最高 98%。
3. 全部普通判定只使用一條公式：

```text
判定結果 = 骰點 - (100 - 技能值) + 總修正
```

4. `判定結果 > 0` 為成功；`<= 0` 為失敗。
5. 正數大小直接表示成功餘裕；負數大小直接表示失敗程度。
6. Buff、Debuff、裝備、能力、GM 難度與環境全部合併成 `總修正`。
7. 特殊效果可以把原本失敗的骰點推成成功。
8. 不再使用獨立的「最低成功骰點 + Margin」雙階段計算。
