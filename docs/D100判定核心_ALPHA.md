# D100 判定核心 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：D100 擲骰方向、單一判定公式、技能值、Buff／裝備／能力／GM 修正、成敗差值。  
> 對抗與極端結果請同時參考 `對抗判定與極端結果_ALPHA.md`。

---

## 1. 骰點方向

D100 採用「高骰較好」方向：

```text
1   = 大失敗
100 = 大成功
```

普通成功／失敗不使用另一套判定方法，而全部由同一條公式處理。

---

## 2. 唯一核心公式

Canonical：

```text
判定結果
= 骰點 - [100 - (技能值 + 總修正)]
```

其中：

```text
骰點      = 原始 D100 結果
技能值    = 角色表上的百分比技能值，天然最高 98
總修正    = Buff、Debuff、裝備、能力、GM 難度、環境等所有判定修正的總和
```

修正方向：

```text
正數修正 = 有利
負數修正 = 不利
```

這條公式同時完成成功率、Buff／Debuff 與最終成敗差值，不再使用第二套計算。

---

## 3. 成敗判讀

```text
判定結果 > 0
→ 成功

判定結果 = 0
→ 失敗，剛好差 1 個有效點進入成功區

判定結果 < 0
→ 失敗
```

因此：

```text
正數越大
→ 成功餘裕越高

負數絕對值越大
→ 失敗程度越嚴重
```

這個最終數字可直接供後續對抗、GM 判斷及 AI 情境解釋使用。

---

## 4. 技能值 = 天然成功率

例：技能值 70，無修正：

```text
100 - (70 + 0)
= 30
```

所以：

```text
骰 31–100
→ 判定結果 > 0
→ 共 70 個成功骰面
→ 70% 成功率
```

例：

```text
骰 80：80 - 30 = +50 → 成功
骰 35：35 - 30 = +5  → 成功
骰 30：30 - 30 = 0   → 失敗
骰 20：20 - 30 = -10 → 失敗
```

---

## 5. 98% 天然技能值上限

角色表上的百分比技能天然永久值最高為 98%。

技能值 98、無修正：

```text
100 - 98 = 2
```

因此：

```text
骰 1：1 - 2 = -1 → 大失敗
骰 2：2 - 2 = 0  → 失敗
骰 3：3 - 2 = +1 → 成功
...
骰 100            → 大成功
```

天然角色表因此永遠保留至少兩個失敗側骰面。

98% 只限制角色表天然永久值，不限制 Buff／裝備／能力可以在實際判定中提供額外修正。

---

## 6. Buff／裝備／能力可以救回一般失敗

例：

```text
技能值 = 70
骰點 = 28
Buff = +5
```

計算：

```text
28 - [100 - (70 + 5)]
= 28 - 25
= +3
→ 成功
```

沒有 Buff：

```text
28 - [100 - 70]
= 28 - 30
= -2
→ 失敗
```

所以正面 Buff 直接提高實際成功率，並可以將原本的一般失敗推成成功。

---

## 7. GM 難度／環境亦放在同一個總修正

不建立第二套難度公式。

例如：

```text
一般情況：GM 修正 +0
有利環境：GM 修正 +10
困難環境：GM 修正 -20
```

全部仍只使用：

```text
判定結果
= 骰點 - [100 - (技能值 + 總修正)]
```

概念上：

```text
總修正
= Buff
+ 裝備
+ 能力
+ GM／環境修正
+ 其他有效來源
```

Resolver 最後只需要一個合計值。

---

## 8. 為何不是「骰點 - 技能值」

如果直接：

```text
骰點 - 技能值
```

技能值 70 時，要得到正數便需要骰 71–100，只有 30 個成功骰面，會把 70% 技能反轉成 30% 成功率。

所以高骰制應使用：

```text
骰點 - [100 - (技能值 + 總修正)]
```

技能越高，括號內數值越低，玩家越容易骰過該差值；Buff 亦以同樣方向提升成功率。

---

## 9. 對抗判定

對抗雙方都先用同一條 D100 公式得到 Result，再比較 Result。

詳細規則見：

```text
對抗判定與極端結果_ALPHA.md
```

目前已鎖定：

```text
Result 較高者勝
Result 完全相同 → 互相抵消／維持現狀／防守方優先
```

例如攻擊與閃避 Result 完全相同，攻擊視為未命中。

---

## 10. 大成功／大失敗

原始 D100：

```text
1   = 大失敗
100 = 大成功
```

但大成功／大失敗不使用全域固定後果表。

Canonical：

```text
極端骰面
+ 行動原意
+ 能力／傷害效果
+ 環境與世界狀態
→ GM + AI 情境推演
→ GM 最終裁決
```

因此：

- 大成功可以代表效果大幅放大，但故事後果未必對玩家有利；
- 大失敗可以令行動嚴重偏離，並在合理情況下產生次生／連鎖事件；
- 不固定為 `大成功 = 雙倍傷害`；
- 不固定為 `大失敗 = 必定打隊友`。

詳細規則見 `對抗判定與極端結果_ALPHA.md`。

# Alpha 鎖定結論

1. D100 高骰較好：原始 1 大失敗、原始 100 大成功。
2. 百分比技能天然永久值最高 98%。
3. 全部普通判定只使用一條公式：

```text
判定結果 = 骰點 - [100 - (技能值 + 總修正)]
```

4. `判定結果 > 0` 為成功；`<= 0` 為失敗。
5. 正數大小直接表示成功餘裕；負數大小直接表示失敗程度。
6. 技能值本身對應天然成功率；技能越高越容易成功。
7. Buff、裝備、能力、GM 難度與環境全部合併成 `總修正`。
8. 特殊效果可以把原本的一般失敗推成成功。
9. 對抗不建立第二套骰法，直接比較雙方 Result；完全相同互相抵消。
10. 大成功／大失敗沒有固定故事後果，由 GM + AI 根據世界狀態進行合理因果推演，GM 最終裁決。
