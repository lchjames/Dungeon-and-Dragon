# 物理專精發揮率模型 — Alpha

> 狀態：Canonical Alpha Override
> 範圍：物理屬性、武器專精、後期倍率、防止雙重成長膨脹。
> 本文件覆蓋較早規格中任何「物理倍率 × 專精倍率」作為兩條獨立成長倍率直接相乘的描述。

---

## 1. 核心問題

如果物理屬性與武器專精都各自提供獨立成長倍率，並直接相乘：

```text
最終物理倍率 = 物理倍率 × 專精倍率
```

則兩者在高階同時成長時會出現明顯的後期乘法膨脹。

因此 Alpha 不採用兩條可無限成長的獨立倍率直接相乘。

---

## 2. 專精改為「物理力量的發揮率」

武器專精仍然代表角色長期使用某類武器所形成的永久熟練與特色，但它不再提供第二條完整傷害倍率。

Canonical：

```text
物理屬性階級
→ 決定角色目前可擁有的物理威力框架／上限

武器專精
→ 決定角色使用該武器時，可以把這個物理威力框架發揮到甚麼程度
```

因此專精是「發揮率／效率修正」，不是另一個獨立乘數成長軸。

---

## 3. 建議計算方式

假設物理階級對某個能力提供基礎倍率：

```text
P = 物理階級所提供的倍率
```

專精提供一個內部發揮係數：

```text
E = 專精發揮率
```

建議 Alpha 公式：

```text
有效物理倍率 = 1 + (P - 1) × E
```

這代表專精只影響「物理階級額外提供的那一段增益」，而不是把整個倍率再次完整乘大。

例：

```text
物理階級倍率 P = 2.50
```

若：

```text
劍類專精發揮率 E = 0.60
```

則：

```text
有效物理倍率
= 1 + (2.50 - 1) × 0.60
= 1.90
```

若日後劍類專精提升至：

```text
E = 1.00
```

則：

```text
有效物理倍率 = 2.50
```

角色只是完整發揮其現有物理階級，而不是再得到第二套 2.50× 類型倍率。

---

## 4. 專精可以沒有玩家可見數值

玩家端不必顯示：

```text
劍專精：73
```

可以只顯示階段／描述，例如：

```text
劍類專精：初習
劍類專精：熟練
劍類專精：精通
劍類專精：大師
```

系統內部可以將各階段映射到發揮率 E。

具體階段數、每階所需修習、各階 E 值全部留到 Alpha Build 調整。

---

## 5. 高階專精是否可以超過 100% 發揮

Alpha 預設應避免大幅超過 100%。

若需要表現真正大師級專精，可以容許非常有限的超額發揮，例如：

```text
E > 1.00
```

但必須設定硬上限，且只允許小幅度超越，例如概念上：

```text
E 上限 ≈ 1.05～1.10
```

實際數字留待 Alpha Build。

這樣即使高階專精可以超越一般人，也不會形成第二條完整後期倍率。

---

## 6. 專精仍可提供非傷害型特色

除了發揮率外，專精可以提供有限、條件式的永久特色，例如：

```text
判定穩定度
來源加值
降低武器懲罰
連擊控制
格擋／反擊修正
破防傾向
擊退穩定度
特定武器能力的效率修正
```

這些效果仍須受能力本身的總威力預算與 Alpha 上限控制。

專精不應同時提供：

```text
完整物理倍率
+
完整專精倍率
+
額外無上限傷害倍率
```

---

## 7. 修習仍可雙軌，但戰鬥倍率不是雙軌

使用劍時仍可同時累積：

```text
物理修習
+
劍類專精修習
```

例如單次有效行動的總成長權重可拆分：

```text
物理 50%
劍類專精 50%
```

具體比例留到 Alpha Build。

但這只是成長紀錄。

戰鬥時：

```text
物理階級
→ 提供威力框架

劍類專精
→ 決定該框架的發揮效率
```

而不是兩個完整倍率相乘。

---

## 8. 魔法與物理的平衡原則

魔法：

```text
火屬性階級
→ 決定火系能力的威力框架／可使用階級
```

物理：

```text
物理階級
→ 決定物理能力的威力框架／可使用階級

武器專精
→ 決定使用特定武器時能否充分發揮該框架
```

因此物理多了一條「風格／熟練」進度，但不因此天然多一條完整傷害倍率。

---

## 9. Alpha 鎖定方向

1. 不使用「物理倍率 × 專精倍率」兩條獨立成長倍率直接相乘。
2. 物理階級決定物理能力的主威力框架。
3. 武器專精是該物理威力的發揮率／效率修正，而不是第二套完整威力倍率。
4. 建議公式：`有效物理倍率 = 1 + (P - 1) × E`。
5. 專精可在玩家端只顯示階段名稱，不必顯示原始數值。
6. 專精內部發揮率、階段、修習需求與上限留到 Alpha Build 調整。
7. 若容許超過 100% 發揮，必須是小幅且有硬上限的 Alpha 可調參數。
8. 專精仍可提供有限的非傷害型永久特色，但不得形成第二套無上限倍率。
9. 使用物理武器仍可同時累積物理修習與專精修習；雙軌成長不等於雙軌傷害倍率。
10. 所有正式數值與角色專精進度仍只保存於 D1。
