# 基礎技能與大成功成長系統 — Alpha

> 狀態：Canonical Alpha Override  
> 範圍：基礎技能、技能點（SP）、使用成長、大成功成長、百分比擲骰天然上限、舊 27 個 Root Skills 的重構。  
> 本文件覆蓋較早規格中「27 個 Root Skills 全部保留」以及以 `Melee / Ranged / Guard / Grapple` 作為獨立基礎技能的描述。`Throw` 保留並正式命名為「投擲」。

---

## 1. 核心分層

角色成長正式分開為：

```text
基礎技能
→ D100 日常／探索／社交／通用行動判定

武器專精
→ 劍、槍／矛、錘、徒手等物理戰鬥方向的長期修習

元素修習
→ 光、暗、火、水、風、土、雷、木等魔法方向的長期修習

能力／招式
→ 火球術、月牙斬、治療術等具名能力；必須透過世界來源取得
```

基礎技能不得再次充當武器專精或具名能力的替代品，以避免重複成長與重複計算。

---

## 2. 所有百分比擲骰技能的天然上限：98%

所有以百分比值進行 D100 判定的角色技能／可擲骰數值，角色表上的**天然永久值最高只能是 98%**。

Canonical：

```text
角色表天然技能值 ≤ 98%
```

「天然值」包括：

- Character Creation 分配；
- SP 永久提升；
- 大成功使用成長；
- 一般永久成長；
- 其他會直接改寫角色基礎技能值的來源。

以上來源均不得令角色表原始技能值自然超過 98%。

Buff／Debuff／裝備／狀態／情境修正屬於**判定時修正**，與角色表天然技能值分開保存，因此可以在計算層另外處理。

但統一 D100 Resolver 必須永遠保留：

```text
自然失敗
大失敗
```

的骰點空間；即使 Buff 令最終判定值高於 98，也不得令所有 D100 結果變成必然成功。

自然失敗與大失敗的精確骰點界線由統一 D100 判定規則定義；本文件先鎖定「天然 98% 硬上限 + 必須保留失敗／大失敗結果」原則。

---

## 3. 基礎技能採雙來源成長（方案 C）

基礎技能可以由兩條途徑成長：

```text
A. 技能點（SP）投入
B. 實際使用造成的成長
```

但使用成長不是每次成功都增加。

Canonical：

```text
只有該基礎技能的有效 D100 判定取得「大成功」
才有資格產生使用成長。
```

普通成功、失敗、大失敗均不因「使用」本身獲得技能成長。

技能點不再用於直接購買／解鎖具名能力。

所有成長來源最終仍受 98% 天然硬上限限制。

---

## 4. 大成功不直接令技能值 +1

為避免高技能因更容易取得大成功而形成過強正回饋：

```text
大成功
→ 獲得該技能的成長進度／成長標記
→ 達到成長條件後才提升技能值
```

Alpha 資料模型應分開保存：

```text
目前技能值
SP 投入來源
使用成長來源
使用成長進度／標記
```

即使成長進度足夠，當天然技能值已達 98% 時，也不得再將永久基礎值提高至 99% 或 100%。

實際每次大成功提供多少成長、多少成長進度換取 +1、以及高技能區間是否需要更多進度，留待 Alpha 平衡測試，不在本文件鎖死。

---

## 5. 防止刷技能

只有「有效判定」可以產生大成功成長。

有效判定至少需要符合：

- 由遊戲系統／GM 認可並記錄的 D100 判定；
- 對當前場景、任務、戰鬥或實際目標具有意義；
- 不是玩家自行反覆宣告同一低風險動作以刷骰；
- 同一行為不得拆成大量無意義判定以重複產生成長機會。

系統不應以「玩家自行輸入我成功使用了技能」直接增加成長。

大成功的精確 D100 判定門檻沿用／交由統一骰點結果系統定義；本文件只規定「只有大成功才觸發使用成長」。

# 6. 重構後的基礎技能表

舊版 27 個 Root Skills 重構為 **23 個基礎技能**。

## A. 感知／心智（6）

```text
察覺
調查
洞察
追蹤
通識
專注
```

### 察覺
即時注意環境中的聲音、動靜、危險、異常與可見細節。

### 調查
主動搜索現場、分析線索、找出隱藏關係或證據。

### 洞察
判讀他人的情緒、意圖、態度、謊言跡象與社交反應。

### 追蹤
辨識並跟隨足跡、痕跡、移動路線或活動留下的證據。

### 通識
角色的一般知識、世界常識、跨領域基礎認知。

### 專注
維持精神集中、在干擾下執行需要持續注意的行動；亦可作部分效果的抵抗基礎之一，但不得取代 SAN／精神狀態系統。

---

## B. 身體／野外（5）

```text
運動
身法
潛行
生存
耐力
```

### 運動
攀爬、跳躍、奔跑、搬運、游泳及一般力量／體能型行動。

**投擲不屬於運動。**

### 身法
平衡、翻越、翻滾、狹窄地形移動及需要精細身體控制的動作。

### 潛行
隱藏自身、安靜移動及避免被發現。

### 生存
野外求生、尋找資源、搭建臨時營地、判斷自然危險等。

### 耐力
長時間體力消耗、疲勞、持續奔跑、惡劣環境下維持行動等。

---

## C. 社交（5）

```text
說服
欺瞞
威嚇
談判
領導
```

### 說服
改變他人態度、令他人接受觀點或採取一般合作行動。

### 欺瞞
說謊、誤導、隱瞞真相、偽造可信敘述。

### 威嚇
以威勢、壓迫、恐懼或明示後果迫使對方服從／退讓。

### 談判
交換條件、議價、協議、利益分配及雙方／多方條件協商。

### 領導
組織隊伍、建立秩序、下達清晰指令、提高群體協作能力。

---

## D. 實務（5）

```text
急救
製作與維修
操作
導航
研究
```

### 急救
現場急救、止血、穩定傷勢及基礎醫療處置；不等於高階醫學能力。

### 製作與維修
製作、修復、拆裝與一般工程／工藝行動。特殊專業可透過能力、背景或條件提供加成／限制。

### 操作
駕駛／操控一般載具、機械、裝置或系統。特殊高科技／特殊載具仍可要求前置能力或資格。

### 導航
辨別方向、閱讀地圖、規劃路線、航行與跨地形定位。

### 研究
透過書本、檔案、電腦、資料庫或其他資訊來源進行系統性資料查找與整理。

---

## E. 通用行動／防禦（2）

```text
投擲
閃避
```

### 投擲
控制拋物的方向、距離、落點與命中，是獨立的 D100 基礎技能。

包括一般投擲物件，以及需要以「投擲」作為基礎判定的行動。

若使用特定投擲武器，武器專精仍可處理該武器本身的長期熟練、能力要求、傷害／效果或其他武器特性；但不得再建立第二個完整百分比命中技能與「投擲」重複計算。

### 閃避
角色不依賴特定武器的通用主動躲避能力。

Alpha 可繼續以 `DEX × 2` 作初始值參考；其後可以由 SP 與符合條件的大成功成長，但天然永久值最高仍為 98%。

# 8. Melee / Ranged / Guard / Grapple 的處理

## Melee / Ranged

如果同時保留：

```text
近戰技能值 + 劍類專精
```

或：

```text
遠程技能值 + 弓類／火器專精
```

會再次產生兩套描述同一戰鬥熟練程度的成長軸。

因此武器／徒手使用能力由對應專精系統處理，不再先經過一個總「近戰／遠程」百分比技能。

`投擲` 是例外的通用基礎技能，因為它描述的是拋物控制本身，而不是一個涵蓋所有遠程武器的總武器熟練度。

`物理` 仍可作傷害／能力分類，但不是基礎技能或角色總物理階級。

## Guard

`格擋／防禦` 是一種行動，不再是一個永久 0–98 Root Skill。

實際判定可由：

- 當前武器專精；
- 防具／盾牌來源；
- 具名防禦能力；
- 其他效果／來源加值

組成。

精確 Combat Resolver 留在戰鬥規則中處理。

## Grapple

一般擒抱、壓制、推撞等基礎身體競爭，可使用 `運動` 作通用基礎。

若角色學會專門摔技、關節技、擒拿術等，則由：

```text
徒手專精
+
具名能力／招式
```

處理，而不是另外存在一條 `Grapple 0–98`。

# 9. 投擲的正式定位

`投擲` 是獨立基礎技能，不屬於 `運動`。

Canonical：

```text
投擲
→ D100 百分比技能
→ 角色表天然值最高 98%
```

它可以處理：

- 將一般物件擲向指定位置；
- 投擲距離與落點控制；
- 投擲攻擊的基礎命中／控制判定；
- 其他 GM 判定應由投擲技巧主導的行動。

若某特定投擲武器另有武器專精，該專精不得再作第二條完整百分比命中技能與 `投擲` 疊加；它主要負責武器特定成長、能力、威力或其他專門效果。

---

# 10. 技能點（SP）的正式角色

技能點主要服務 **基礎技能成長**。

Canonical：

```text
SP
→ 提升基礎技能
→ 最高提升至天然 98%
```

禁止預設：

```text
SP
→ 點擊解鎖火球術
SP
→ 點擊解鎖月牙斬
```

具名能力仍需要導師、師傅、學校、卷軸、秘籍、商店、任務、劇情、物品、覺醒、GM 授予等世界來源。

Character Level 升級可繼續授予 SP，但：

- 每級實際授予多少 SP；
- 不同技能區間的 SP 成本；
- 是否 `1 SP = +1`；
- 高技能是否提高成本；

均留待 Alpha Balance 調整。

---

# 11. Character Creation

建立角色時：

- Creation Skill Points 只分配到基礎技能；
- 任何百分比基礎技能的天然最終值不得高於 98%；
- 不用 Creation SP 購買具名能力；
- 不用 Creation SP 直接提高元素修習或武器專精；
- 元素／武器專精的起始狀態由其自身規則、背景、職業、世界來源或 GM 設定處理。

既有 Creation Skill Point Pool 公式與較低的「起始角色建立硬上限」仍可作 Alpha working default；若建立階段使用 70 等較低上限，98% 仍只是整個角色自然成長生命週期的絕對天花板，而不是起始值。

# 12. 使用成長資料與審計

D1 應保存每次正式技能成長的來源，至少可區分：

```text
CREATION_SP
LEVEL_SP
GREAT_SUCCESS_GROWTH
GM_ADJUSTMENT
OTHER_APPROVED_SOURCE
```

大成功成長事件應可追蹤：

```text
角色
技能
判定事件
骰點結果
是否大成功
成長進度變化
最終是否令技能值提升
時間
Campaign / Session 關聯（如有）
```

不得使用 localStorage 作永久成長紀錄。

# 13. Alpha 鎖定結論

1. 基礎技能採「SP + 使用成長」雙來源。
2. 使用成長只會在有效 D100 判定取得大成功時觸發。
3. 大成功先產生成長進度／標記，而不是直接令技能值 +1。
4. 普通成功、失敗、大失敗不因使用本身增加技能成長。
5. 只有系統／GM 認可的有意義判定可以產生成長，禁止刷骰。
6. 舊 27 Root Skills 重構為 **23 個基礎技能**。
7. `Melee`、`Ranged`、`Guard`、`Grapple` 移出基礎技能。
8. `Throw` 正式保留為「投擲」，並且是獨立基礎技能，不屬於 `運動`。
9. `Dodge`／閃避保留為通用防禦基礎技能。
10. 所有以百分比作 D100 判定的角色表天然技能值硬上限為 **98%**。
11. Buff／Debuff 為判定時修正，不改寫 98% 天然角色表值；統一 D100 Resolver 仍必須保留自然失敗與大失敗。
12. 武器戰鬥熟練度由武器／徒手專精處理，不再與通用近戰／遠程技能重複。
13. SP 主要提升基礎技能，不直接購買具名能力。
14. 每級 SP 數量、SP 成本、大成功成長進度換算與高技能曲線均留待 Alpha Balance 調整。
15. 所有永久技能值與成長歷史保存於 D1。
