# 對抗判定與極端結果 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：對抗判定、負面效果優先保護、平手、命中與效果分離、大成功／大失敗、GM + AI 情境推演。  
> 本文件與 `D100判定核心_ALPHA.md` 一起使用；若較早 Combat 文件仍使用舊式獨立命中公式，本文件與最新 D100 核心優先。

---

# 1. 核心原則：機械結果 ≠ 故事好壞

D100 結果首先描述角色把自己想做的事情做得有多好／多差，而不是直接描述事件最後對玩家有多有利／多不利。

因此：

```text
大成功 ≠ 一定是好事
大失敗 ≠ 一定只是甚麼也沒有發生
```

故事後果仍需考慮能力／物品效果、目標、附近角色、環境、材質、既有狀態、Damage Profile、Ability Profile 與合理因果鏈。

---

# 2. 對抗判定沿用同一 D100 Result

雙方均使用：

```text
Result = 骰點 - [100 - (技能值 + 總修正)]
```

不建立另一套對抗專用骰法。

一般競爭型對抗：

```text
A Result > B Result
→ A 勝出

A Result < B Result
→ B 勝出
```

---

# 3. 負面效果必須「嚴格壓過」對方抵抗

凡行動目的是向另一方施加負面後果，例如：

```text
傷害
Debuff
控制
束縛
魅惑
恐懼
擊退
擊倒
沉默
中毒
其他不利狀態
```

主動施加者必須令自己的對抗 Result **嚴格高於** 目標的防禦／閃避／抵抗 Result，才可進入後續效果結算。

Canonical：

```text
施加方 Result > 抵抗方 Result
→ 成功突破
→ 進入效果／傷害結算

施加方 Result <= 抵抗方 Result
→ 未突破
→ 負面效果不成立
```

這代表受負面影響的一方在完全平手時有輕微優勢。

此規則不是額外數值 Bonus，而是 Tie Rule／Resolution Priority。

---

# 4. 完全相同 = 互相抵消；負面效果不成立

例如：

```text
攻擊 Result = +32
閃避 Result = +32

→ 攻擊沒有嚴格壓過閃避
→ 視為未命中
→ 不進入傷害計算
```

同樣：

```text
控制術 Result = +41
精神抵抗 Result = +41

→ 控制未能壓過抵抗
→ 不施加控制狀態
```

所以：

```text
平手
→ 維持較安全／原本狀態
→ 不新增負面後果
```

不需重骰或隱藏 Tie Breaker。

---

# 5. 命中是傷害結算的入口，不是傷害本身

攻擊流程：

```text
攻擊 Result
vs
閃避／其他命中防禦 Result

只有攻擊 Result > 防禦 Result
↓
命中成立
↓
才進入 Damage Resolution
```

因此容許：

```text
Miss
→ 未通過閃避／命中對抗

Hit but Ineffective
→ 已命中
→ 但之後威力不足以突破防禦／護甲／抗性

Hit and Effective
→ 已命中
→ 並造成有效傷害／效果
```

所以正式鎖定：

```text
命中 ≠ 一定造成有效傷害
```

傷害／效果與防禦的具體數值模型由後續 Damage/Effect Resolution 規則處理。

---

# 6. 此原則同樣適用於非傷害負面效果

例如 Debuff：

```text
詛咒施加 Result
vs
目標抵抗 Result

施加方 <= 抵抗方
→ 詛咒失敗

施加方 > 抵抗方
→ 詛咒成功穿過抵抗
→ 再依 Ability Profile 施加 Debuff
```

因此所有「我要令對方變差」的效果都需要先真正突破對方。

---

# 7. 大成功／大失敗不使用固定後果表

原始 D100：

```text
1   = 大失敗
100 = 大成功
```

但不建立全域固定規則，例如：

```text
大成功 = 傷害 ×2
大失敗 = 必定打隊友
```

極端結果由 GM 最終裁決；AI 協助情境推演。

---

# 8. 大成功：效果高度實現／放大，但不保證有利

大成功代表行動本身被極高程度實現、放大或超額完成。

例如召喚水：

```text
普通成功
→ 召出正常所需水量

大成功
→ 水量／範圍／持續等效果之一被顯著放大
```

在野外可能非常有利；在密閉房間可能造成淹水與後續環境危險。

因此：

```text
機械上：大成功
故事上：可以引發麻煩
```

大成功不代表 AI 可以無視 Ability Rank、Scale、MP、Profile 或世界物理而任意無限放大。

---

# 9. 大失敗：行動嚴重偏離，可能產生次生／連鎖事件

普通失敗通常可直接結束：

```text
攻擊未命中
→ 沒有傷害
```

大失敗可進一步考慮力量／投射物／魔法實際去了哪裡，例如：

```text
打中隊友
擊中牆壁／地板
武器脫手
打碎物件
擊中承重結構
擊穿管線／容器
觸發陷阱
引發其他合理事件
```

但不使用固定懲罰表。

若打中地板，亦不得自動假設地板穿洞；需再考慮攻擊威力、材質、厚度、既有損傷與 Damage Profile，之後才可推演可能連鎖反應。

---

# 10. AI 極端結果建議：1–3 個選項

AI 在大成功、大失敗或其他高歧義極端事件時，應根據當前世界狀態向 GM 提供 **1–3 個合理建議**。

建議數量：

```text
只有一個明顯合理結果
→ 1 個建議

存在數個合理方向
→ 2–3 個建議
```

每個建議至少包含：

```text
直接結果
可能的次生／連鎖結果
簡短因果解釋
```

例如大失敗攻擊可建議：

```text
A. 武器擊中旁邊石柱，造成武器卡住
B. 攻擊偏向隊友，需要按原 Damage Profile 結算
C. 擊中已受損地板，可能觸發結構破壞檢查
```

AI 不得自行決定最終故事結果。

GM 可以：

```text
接受其中一項
修改其中一項
拒絕全部並自行裁決
```

---

# 11. 大成功／大失敗與技能成長

基礎技能使用成長仍沿用：

```text
有效 D100 判定出現大成功
→ 有資格取得該技能的大成功成長進度
```

即使大成功的放大效果導致不利故事後果，它仍然是大成功，不會因此自動失去成長資格。

---

# 12. Alpha 鎖定結論

1. 對抗雙方沿用同一 D100 Result。
2. 一般對抗比較 Result，較高者勝。
3. 任何要向對方施加負面後果的行動，必須嚴格壓過目標防禦／抵抗 Result。
4. 負面效果對抗平手時，受影響一方優先；負面效果不成立。
5. 攻擊必須先嚴格突破閃避／命中防禦，才可進入傷害計算。
6. 命中不等於一定造成有效傷害；可以命中但被防禦／護甲／抗性完全抵消。
7. 同一原則適用於 Debuff、控制、束縛、魅惑、擊退等負面效果。
8. 原始 1 為大失敗；原始 100 為大成功。
9. 大成功／大失敗不使用全域固定後果表。
10. 大成功描述效果高度實現／放大，不代表故事必然有利。
11. 大失敗可因世界狀態形成合理次生／連鎖反應，但不得憑空生成。
12. AI 在極端／高歧義結果時提供 1–3 個情境合理建議；GM 為最終裁決者。
13. 所有連鎖結果仍須遵守既有 Ability、Damage、Scale、環境與世界狀態。
