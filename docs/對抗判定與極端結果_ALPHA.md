# 對抗判定與極端結果 — Alpha

> 狀態：Canonical Alpha Working Rule  
> 範圍：對抗判定、負面效果優先保護、平手、命中與效果分離、大成功／大失敗、防守 Great、GM + AI 情境推演。  
> 本文件與 `D100判定核心_ALPHA.md` 一起使用；非傷害效果的具體 Great Interaction 以 `非傷害效果結算_ALPHA.md` 為優先。

---

# 1. 核心原則：機械結果 ≠ 故事好壞

D100 Result 描述角色把自己想做的事情做得有多好／多差，而不是直接描述事件最後對玩家有多有利／不利。

```text
大成功 ≠ 一定是好事
大失敗 ≠ 一定是壞事
```

極端結果仍需考慮 Ability、Damage Profile、目標 Profile、附近角色、環境、材質與合理因果鏈。

---

# 2. 對抗沿用同一 D100 Result

雙方均使用：

```text
Result = 骰點 - [100 - (技能值 + 總修正)]
```

一般：

```text
A Result > B Result → A 勝
A Result < B Result → B 勝
```

不建立另一套對抗骰法。

---

# 3. 負面效果必須嚴格壓過抵抗

凡目的是向另一方施加負面後果，例如：

```text
傷害
減益
控制
束縛
魅惑
恐懼
擊退
擊倒
沉默
中毒
其他不利狀態
```

都使用：

```text
施加方 Result > 抵抗方 Result
→ 成功突破

施加方 Result <= 抵抗方 Result
→ 未突破
→ 負面效果不成立
```

因此平手時受影響一方有微小優勢。

這不是數值 Bonus，而是 Tie Resolution Priority。

---

# 4. 100 vs 100 仍然受平手／弱勢方規則約束

原始骰 100 不代表無條件勝利。

如果雙方都是 100：

```text
仍比較最終 Result
```

```text
施加方 Result > 抵抗方 Result
→ 施加方勝

施加方 Result < 抵抗方 Result
→ 抵抗方勝

施加方 Result = 抵抗方 Result
→ 負面效果未能嚴格突破
→ 抵抗方勝
```

所以：

```text
100 vs 100 完全平手
→ 防守／抵抗成功
```

Great 只在基本勝負確定後，用來描述／放大勝方或解讀極端行動，不會跳過對抗核心規則。

---

# 5. 命中只是傷害結算入口

```text
攻擊 Result > 閃避／命中防禦 Result
→ 命中
→ 才進入 Damage Resolution
```

可能結果：

```text
Miss
→ 未突破閃避

Hit but Ineffective
→ 已命中
→ 傷害仍被固定防禦／抗性擋住

Hit and Effective
→ 已命中且造成有效傷害
```

因此：

```text
命中 ≠ 一定扣 HP
```

---

# 6. 防守／抵抗正式有自己的 Great Result

抵抗方的原始 100／1 不應被忽略。

## 抵抗大成功（原始 100）

仍先看最終 Result。

如果抵抗方成功或平手勝出：

```text
→ 完美防守／完美抵抗
→ 原負面效果不成立
→ AI + GM 可提供 1–3 個防守優勢建議
```

可能包括：

```text
閃避後取得更好位置
順勢進入掩體
把力量導向安全方向
看穿能力運作方式
維持極佳架勢
令束縛／投射物落到無害位置
```

不自動給固定 +X、免費反擊或免費 Buff。

如果抵抗方雖然骰 100，但最終 Result 仍被來源方壓過：

```text
→ 仍然被突破
```

可敘事成「已做到自身極限，但仍被更強力量壓過」。

## 抵抗大失敗（原始 1）

```text
→ 防守／抵抗行動嚴重失誤
```

AI + GM 可提供 1–3 個合理失誤，例如：

```text
失去平衡
移錯方向
暴露位置
撞上障礙物
架勢崩壞
錯判攻擊方向
```

但：

```text
抵抗大失敗 ≠ 自動令來源效果 ×2
```

避免與來源大成功疊成 ×4。

---

# 7. 來源方 Great 與防守方 Great 的分工

來源方 Great 主要描述：

```text
能力／攻擊本身施展得極好或嚴重偏離
```

抵抗方 Great 主要描述：

```text
閃避／格擋／意志／抗性行動的極端表現
```

兩者都可以參與同一事件，但核心勝負仍由 Result + 平手優先規則決定。

具體非傷害效果：

```text
來源大成功 → 成功落地時主要效果值 ×2
來源大失敗 → 進入偏離結果
抵抗大成功 → 完美防守 + 1–3 個優勢建議
抵抗大失敗 → 防守失誤 + 1–3 個後果建議
```

詳細規則見 `非傷害效果結算_ALPHA.md`。

---

# 8. 雙重大失敗可形成「兩錯相消」

直接對抗中，如果來源方與抵抗方都擲出原始 1，可依非傷害效果規則形成：

```text
兩個錯誤互相抵消
→ 原本效果意外落在原本目標
→ 正常強度
```

這是特殊 Great Interaction，不代表大成功，也不 ×2。

---

# 9. 大成功／大失敗與世界結果

來源方大成功可以代表效果高度實現／放大，但不保證對角色有利。

例如召喚水大成功在密閉房間可能造成淹水。

來源方大失敗則代表行動嚴重偏離，可誤中自己、隊友、其他敵人、環境或物件；但意外結果可能因目標 Profile 反而幫到玩家。

例如：

```text
治療術大失敗
→ 誤中不死敵人
→ 不死 Profile 把治療轉成傷害
```

仍然是大失敗，因為原本意圖沒有被正確完成。

---

# 10. AI 極端結果建議：1–3 個

AI 在以下情況可提供 1–3 個合理建議：

```text
來源大成功／大失敗
抵抗大成功／大失敗
雙方同時 Great
特殊環境／材質／種族互動
結果可能產生次生／連鎖事件
```

每個建議至少包括：

```text
直接結果
可能次生結果
簡短因果解釋
```

GM 可以接受、修改或拒絕全部建議。

AI 不得跳過 Result 規則、把 100 當無條件勝利，或偷偷創造免費 Buff／Debuff／反擊。

---

# 11. Great 與技能成長

基礎技能大成功成長仍看原始 D100 大成功標記。

即使：

```text
骰 100
→ 對抗最後仍被更強抵抗擋住
```

該角色仍確實擲出大成功；是否符合「有效／有意義判定」等成長條件，按基礎技能成長規則處理。

---

# 12. Alpha 鎖定結論

1. 對抗雙方使用同一 D100 Result。
2. 負面效果來源方必須嚴格高於抵抗方才可突破。
3. 平手時受影響／抵抗方優先，負面效果不成立。
4. **100 vs 100 仍正常比較 Result；完全平手時抵抗方勝。**
5. 100 不是無條件成功，1 亦不單純等於固定懲罰。
6. 攻擊先突破閃避才進入傷害結算；命中不等於一定扣 HP。
7. 抵抗方正式有 Great 系統。
8. 抵抗大成功若成功防守，可由 AI + GM 提供 1–3 個防守優勢建議；不自動給固定數值收益。
9. 抵抗大失敗可有 1–3 個防守失誤後果；不自動令來源效果 ×2。
10. 來源 Great 與抵抗 Great 可以共同影響事件敘事，但基本勝負由 Result + Tie Rule 決定。
11. 雙重大失敗可依專門效果規則形成兩錯相消的意外成功。
12. AI 提供 1–3 個情境合理建議；GM 為最終裁決者。
13. 所有後果仍須遵守 Ability、Damage、Effect、Scale、目標 Profile 與世界狀態。
