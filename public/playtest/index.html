PD&D Campaign HubAlpha 試玩指引

START PLAYING

現在就可以開始

先試建角，再由 GM 安排一場短戰鬥。目前是 Alpha 版本，適合實際操作及回報問題。

1. 自行建角

  1. 建立玩家：自訂 User 及 4 位數 Key；已有帳號便直接登入。
  2. 按「+ New Character」，輸入角色名稱並檢查擲出的屬性，建立 Draft Character。
  3. 開啟角色的「Creation Skills」，在 23 個基礎技能中分配全部 200 點，每個技能最多 30 點。
  4. 按「Finalize Character」完成建角。確認後，建角技能配置會鎖定。
  5. 在 Notes 寫一段筆記並儲存；重新整理頁面，確認角色及筆記仍在。

純粹試流程可用六個技能各 30 點、另一個 20 點，其餘 0 點；這是測試配置，並非配點建議。

建立玩家 玩家登入

2. 準備一場實際遊戲

完整地圖與戰鬥需要 GM 準備內容。玩家帳號不能自行開局；自己同時測兩邊時，可用另一個瀏覽器設定檔登入 GM。

  • GM 使用既有管理員帳號登入，為測試角色配置有效的 Attack Profile。
  • 建立測試 Scenario、Scene 及 Encounter，加入角色與敵人，再開始 Combat。
  • 要測地圖，另需設定地圖、啟用場景 Runtime 並放置角色。
  • 背包裝備、能力、貨幣匯率及 Story 敘事，需要 GM 提供相應內容；新角色看到空白清單不一定是故障。
GM 登入

3. 第一輪驗收

玩家輪到自己時選擇攻擊及目標，確認結果、HP 和回合更新；由 GM 結束戰鬥，再另外 Resolve Encounter。地圖已設定的話，再試移動與閱讀已揭露的敘事。

遇到問題時，記下角色名稱、頁面、剛按的按鈕、預期結果與實際結果，附上錯誤畫面；毋須提供 Key 或密碼。

操作會儲存至正式遊戲資料。建議角色及場景名稱加上「測試」，以便與日常遊戲區分。
